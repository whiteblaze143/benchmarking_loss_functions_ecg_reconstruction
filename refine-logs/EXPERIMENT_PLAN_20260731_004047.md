# Experiment Plan: Mixed-Level Loss Benchmark and Clinical Diagnostic Atlas

**Problem:** Identify architecture-conditional loss effects without mistaking morphology gains for clinical preservation.

**Method thesis:** A complete paired factorial design plus dataset-specific diagnostics is required; no single aggregate metric can adjudicate the loss functions.

## Planning Gate

- Stable thesis: benchmark interaction/trade-off structure.
- Dominant contribution: 160-condition mixed-level loss study repeated across three seeds.
- Rejected complexity: new architecture, weighted omnibus score, forced foundation-model primitive.
- Remaining concerns: checkpoint completeness, seed variance, LUDB boundary matching, ISP provenance, rare-task uncertainty, external preprocessing.
- Frontier primitive: absent by design.

## Claims and Minimum Evidence

| Claim | Minimum evidence | Decision gate |
|---|---|---|
| C1 loss effects depend on endpoint and training seed | complete mixed-level grid; paired main effects/interactions | no claim if grid incomplete or interactions unestimable |
| C2 morphology and diagnostic utility can diverge | paired morphology/classifier changes with CIs | investigate preprocessing before interpreting discordance |
| C3 selected masks transfer without tail failure | LUDB, EchoNext, Sunnybrook, noise, subgroup panels | reject deployment framing if tails/subgroups fail |

## Block A: Checkpoint and Manifest Integrity

- Enumerate 160 masks per required seed: fixed MSE, five binary toggles, and MMD kernel in {0,1,2,3,4}.
- Verify checkpoint readability, sidecars, source revision, factor names/weights.
- Assert common PTB-XL train/validation/test inventory hashes.
- Preserve failed/partial/skipped status.
- **Output:** completeness matrix and immutable evaluation manifest.
- **Priority:** blocking.

## Block B: PTB-XL Primary Factorial Analysis

- **Cohort:** folds 1–8 train, 9 validation, 10 test; 2,198 test records / 1,904 patients.
- **Primary endpoints:** genuinely missing-lead Pearson, QRS correlation, ST correlation, amplitude error.
- **Secondary:** MSE/MAE/R2/SNR, derivative error, J-point MAE, R-peak timing.
- **Inference:** paired patient-cluster BCa intervals; prespecified main effects/interactions; multiplicity.
- **Deletion study:** smallest mask statistically compatible with selected full mask.

## Block C: Diagnostic Utility and Calibration

- PTB-XL ECGFounder 150-task and five-superclass heads.
- EchoNext official frozen 12-task waveform-plus-seven-covariate SHD classifier.
- Report per-task AUROC/AP/F1, Brier/log loss/ECE, probability drift, threshold agreement.
- Non-inferiority only with justified prespecified margins.
- Identify morphology–diagnostic discordant records algorithmically.

## Block D: LUDB Delineation

- **Data:** 200 records, 12×5,000, 500 Hz, per-lead annotations.
- Parse onset–peak–offset triplets with a validated state machine.
- Beat-aware one-to-one matching within a prespecified tolerance.
- Report sensitivity/PPV and signed/absolute onset/offset errors by wave/lead.
- Aggregate by record/patient rather than treating boundaries as independent.
- Compare source-delineator error with reconstructed-delineator error.

## Block E: ISP Provenance and Interval Validation

- Validate 403/72 rows and all serialized intervals.
- Obtain authoritative class mapping, sampling rate, raw waveform link, and subject split.
- Until provenance is resolved, report widths in samples only.
- Do not use ISP for waveform claims if raw signals cannot be linked.

## Block F: External Transfer

### EchoNext

- Verify inverse normalization, µV→mV, axis order, 250→500 Hz resampling.
- Evaluate 5,442 test records; retain support for all 12 endpoints.
- Disclose unchanged tabular covariates and add tabular-only/waveform-masked counterfactuals before making waveform-attribution claims.
- Subgroup by age, sex, race/ethnicity, setting, and acquisition year where event counts permit.

### Sunnybrook

- Evaluate 20 fully measured Philips records.
- Retain ECG008/ECG010 transients; report robust and sensitivity summaries.
- Keep Philips statement labels explicitly proxy/non-adjudicated.

### Smartwatch/device

- Evaluate four paired device/simulator conditions separately.
- Investigate 179 versus 180 Samsung record pairing.
- Avoid prospective-human claims.

## Block G: Noise, SQI, Fairness, and Abstention

- 17 paired corruption conditions with deterministic realization IDs.
- Noise-family-specific morphology and classifier degradation.
- Source/reconstructed signal-quality probability fidelity.
- Patient-cluster age/sex reconstruction-induced gaps.
- Risk–coverage curves overall and by subgroup/device/noise.
- Treat electrode-problem classification as exploratory (3 positives).

## Run Order

1. Lock factor semantics and checkpoint manifest.
2. Smoke-test one anchor mask through every dataset adapter.
3. Validate record hashes and per-record output schemas.
4. Run PTB-XL primary endpoints.
5. Run classifier/calibration endpoints.
6. Run LUDB delineation and external transfer.
7. Run noise/subgroup/abstention diagnostics.
8. Freeze tables; only then run confirmatory inference.

## Stop/Go Rules

- Stop if factor names or checkpoint provenance are ambiguous.
- Stop a dataset endpoint if units/rate/lead order cannot be verified.
- Re-run if record hashes differ between cells.
- Reframe if morphology improves but diagnostic margins fail.
- Prefer a smaller mask when extra components lack consistent benefit.
- Report incomplete cells instead of imputing or silently dropping them.

## Resource Notes

Training dominates cost and is already in progress. Evaluation is mostly inference/CPU morphology work, but LUDB delineation and 160-condition-per-seed record storage require explicit scheduling. Runtime estimates must come from measured smoke runs, not the prior unsupported “~1 hour” claim.
