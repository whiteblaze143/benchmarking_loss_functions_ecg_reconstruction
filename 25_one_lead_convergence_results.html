6.1 Why this is separate from screening

The original factorial queue used short screening runs. This chapter contains only the promoted longer-budget extensions. A 3-, 10-, and 15-epoch result for the same named architecture are different estimands because training budget and checkpoint selection changed. The longest result supersedes the shorter result for final ranking, but the shorter trajectory remains useful for diagnosing whether screening preserved the ordering.

## Why this is separate from screening

The original factorial queue used short screening runs. This chapter contains
only the promoted longer-budget extensions. A 3-, 10-, and 15-epoch result for
the same named architecture are different estimands because training budget and
checkpoint selection changed. The longest result supersedes the shorter result
for final ranking, but the shorter trajectory remains useful for diagnosing
whether screening preserved the ordering.
