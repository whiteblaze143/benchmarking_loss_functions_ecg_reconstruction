3.2 Registered comparison hierarchy

The principal comparison is:

A0 → A0 + wavelet → A0 + wavelet + SSL.

E1 is reserved for complementarity:

A0 + wavelet + SSL versus E1 + wavelet + SSL.

Current 1110000 evidence does not authorize calling E1 an improved base architecture. The highest-value mechanism contrast is matched Morlet magnitude + Morlet phase versus Morlet magnitude + UEG-repolarization phase. A replicated gain concentrated on T-on/T-off would be consistent with the physiological second-view hypothesis, but detector artifacts, leakage, and generic regularization remain alternative explanations requiring controls.

## Registered comparison hierarchy

The principal comparison is:

`A0 → A0 + wavelet → A0 + wavelet + SSL`.

E1 is reserved for complementarity:

`A0 + wavelet + SSL` versus `E1 + wavelet + SSL`.

Current `1110000` evidence does not authorize calling E1 an improved base
architecture. The highest-value mechanism contrast is matched **Morlet
magnitude + Morlet phase** versus **Morlet magnitude + UEG-repolarization
phase**. A replicated gain concentrated on T-on/T-off would be consistent with
the physiological second-view hypothesis, but detector artifacts, leakage, and
generic regularization remain alternative explanations requiring controls.

## Performance-profile UMAP

This embedding groups completed runs by standardized outcome vectors. It helps
spot configurations that trade reconstruction for delineation and repeated
runs that unexpectedly separate. It is not a neural latent-space UMAP.
