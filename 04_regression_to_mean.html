25  Rigorous Agreement & The Mathematics of Regression to the Mean

At the unrestricted population-risk optimum, squared-error regression returns the conditional mean E[Y\mid X]. This theorem motivates—but does not prove for a finite trained network—the hypothesis that ambiguous missing-lead structure may be attenuated. Peak amplitude, interval timing, morphology, and clinical classification therefore remain empirical endpoints; none follows automatically from the theorem.

This chapter presents the complete mathematical proof of L_2 variance shrinkage, followed by an advanced statistical battery using Bland-Altman Agreement Analysis.

25.1 Mathematical Proof: Why L_2 Minimization Induces Regression to the Mean

25.1.1 Theorem 1: L_2 Minimization Yields the Conditional Expectation

Let X \in \mathbb{R}^{C_{in} \times T} be the input lead tensor and Y \in \mathbb{R}^{C_{out} \times T} be the target 12-lead tensor with joint probability density p(X, Y).

Objective: Find a neural network function f^*(X) minimizing the expected squared error:

f^*(X) = \arg\min_f \mathbb{E}_{(X, Y)} \left[ \| f(X) - Y \|_2^2 \right]

Proof: Using the law of total expectation, we expand the expected loss:

\mathbb{E}_{(X,Y)} \left[ \| f(X) - Y \|_2^2 \right] = \mathbb{E}_{X} \left[ \mathbb{E}_{Y|X} \left[ \| f(X) - Y \|_2^2 \;\middle|\; X \right] \right]

To minimize the outer expectation, we minimize the inner conditional expectation point-wise for every fixed value of X = x:

\mathcal{L}(f(x)) = \int (f(x) - y)^2 \, p(y \mid x) \, dy

Differentiating \mathcal{L}(f(x)) with respect to f(x) and setting the derivative to zero:

\frac{\partial \mathcal{L}}{\partial f(x)} = \int 2 \cdot (f(x) - y) \, p(y \mid x) \, dy = 0

2 \cdot f(x) \int p(y \mid x) \, dy - 2 \int y \cdot p(y \mid x) \, dy = 0

Since \int p(y \mid x) \, dy = 1:

f^*(x) = \int y \cdot p(y \mid x) \, dy = \mathbb{E}[Y \mid X = x]

\blacksquare

25.1.2 Corollary 1: Marginal variance of the conditional mean

By the Law of Total Variance:

\operatorname{Var}(Y) = \operatorname{Var}\big(\mathbb{E}[Y \mid X]\big) + \mathbb{E}\big[\operatorname{Var}(Y \mid X)\big]

Since \operatorname{Var}(Y \mid X) \ge 0, it follows that:

\operatorname{Var}\big(f^*(X)\big) = \operatorname{Var}\big(\mathbb{E}[Y \mid X]\big) \le \operatorname{Var}(Y)

For a scalar coordinate, equality holds when the expected conditional variance is zero. For a waveform tensor, the corresponding statement is coordinatewise or in terms of the conditional covariance matrix. Whether a particular lead set leaves nonzero conditional uncertainty is a property of the data distribution and cannot be inferred merely from the number of observed leads.

This is a marginal-distribution statement about the population optimum. It does not imply that every finite L_2 model shrinks QRS peaks or flattens P/T waves. Those are prespecified hypotheses to test with paired record-level amplitude and delineation endpoints, detector-failure denominators, and patient-clustered uncertainty.

25.1.3 Wasserstein-1 Distance (W_1 Earth Mover’s Metric)

To quantify the total probability mass shift caused by variance shrinkage, we compute the 1D Wasserstein-1 Distance (W_1) between the empirical cumulative distribution functions F_P(u) (ground truth) and F_Q(u) (prediction):

W_1(P, Q) \triangleq \inf_{\gamma \in \Pi(P, Q)} \mathbb{E}_{(x, y) \sim \gamma} \left[ \|x - y\|_1 \right] = \int_{-\infty}^{\infty} \left| F_P(u) - F_Q(u) \right| \, du

where \Pi(P, Q) denotes the set of all joint distributions whose marginals are P and Q.

  • Physical Interpretation: W_1 measures the minimum “work” (probability mass \times transport distance) required to transform the predicted peak amplitude distribution Q into the true physiological distribution P.
  • Separate estimands: training with a finite-weight mini-batch MMD term does not guarantee that held-out W_1 is zero. MMD and W_1 must be measured separately under the registered evaluation protocol; any association between them is an empirical result.

25.2 Why Pearson Correlation (r) Cannot Prove Agreement

A common misconception in model evaluation is using Pearson’s correlation coefficient (r) to claim reconstruction accuracy. As proved by Giavarina (2015): - Pearson correlation measures linear association, not agreement. - If \hat{Y} = 0.5 \cdot Y + 0.1, the correlation is perfect (r = 1.0), yet the predicted amplitudes suffer a 50\% clinical loss!

To measure true clinical comparability, we must use Bland-Altman Agreement Analysis.

25.3 Advanced Bland-Altman Statistical Battery

The didactic battery below illustrates four agreement summaries or diagnostics; it is not four non-parametric hypothesis tests:

  1. Mean Bias (\bar{d}): \bar{d} = \frac{1}{N} \sum_{i=1}^{N} d_i, \quad d_i = \hat{y}_i - y_i
  2. 95% Limits of Agreement (LoA): \text{LoA} = \left[ \bar{d} - 1.96 \cdot s_d, \;\; \bar{d} + 1.96 \cdot s_d \right], \quad s_d = \sqrt{\frac{1}{N-1} \sum_{i=1}^{N} (d_i - \bar{d})^2}
  3. Non-Parametric BCa Bootstrap Confidence Intervals (9,999 Resamples): Constructs 95% Confidence Intervals for \bar{d} without assuming Gaussian errors.
  4. Levene’s Test as a limited diagnostic: Tests a grouped variance null; failure to reject does not verify homoscedasticity. A continuous difference-versus-mean model and residual visualization are needed for proportional-bias assessment.

Code 
import torch
import numpy as np
import plotly.graph_objects as go
from scipy import stats

def compute_ba_statistics(pred_peaks, target_peaks, model_name):
    """
    Computes Bland-Altman agreement statistics: Mean Bias, 95% LoA, 
    BCa Bootstrap 95% CI, Shapiro-Wilk Normality, and Levene Homoscedasticity.
    """
    diff = pred_peaks - target_peaks
    mean_val = (pred_peaks + target_peaks) / 2.0
    
    bias = np.mean(diff)
    std_diff = np.std(diff, ddof=1)
    
    loa_lower = bias - 1.96 * std_diff
    loa_upper = bias + 1.96 * std_diff
    
    # 1. Non-parametric BCa Bootstrap for Bias 95% CI (9,999 resamples)
    res = stats.bootstrap(
        (diff,), np.mean, 
        confidence_level=0.95, n_resamples=9999, method='BCa'
    )
    ci_lower, ci_upper = res.confidence_interval
    
    # 2. Shapiro-Wilk test for normality of differences
    stat_sw, p_value_sw = stats.shapiro(diff)
    normality_msg = "Normality not rejected" if p_value_sw > 0.05 else "Normality rejected"
    
    # 3. Levene's Test for Homoscedasticity (Lower half vs Upper half)
    median_val = np.median(mean_val)
    diff_lower = diff[mean_val <= median_val]
    diff_upper = diff[mean_val > median_val]
    stat_lev, p_value_lev = stats.levene(diff_lower, diff_upper)
    levene_msg = "Equal-variance null not rejected" if p_value_lev > 0.05 else "Equal-variance null rejected"
    
    # 4. Percentage bias calculation
    pct_diff = (diff / mean_val) * 100
    pct_bias = np.mean(pct_diff)
    
    print(f"=== {model_name} Bland-Altman Audit ===")
    print(f"Mean Bias (\u0304d): {bias:.4f} mV (BCa 95% CI: [{ci_lower:.4f}, {ci_upper:.4f}])")
    print(f"Limits of Agreement (95% LoA): [{loa_lower:.4f}, {loa_upper:.4f}]")
    print(f"Shapiro-Wilk Normality Test: p = {p_value_sw:.4f} ({normality_msg})")
    print(f"Levene Homoscedasticity Test: p = {p_value_lev:.4f} ({levene_msg})")
    print(f"Percentage Bias: {pct_bias:.2f}%")
    print("-" * 50)
    
    return mean_val, diff, bias, loa_lower, loa_upper, pct_diff, pct_bias

# Simulate N=300 peak amplitudes to demonstrate the statistical interface only
np.random.seed(42)
target_peaks = np.random.normal(1.2, 0.4, 300)

# 1. Stipulated MSE Model (30% amplitude attenuation factor)
mse_peaks = target_peaks * 0.70 + np.random.normal(0, 0.03 * np.abs(target_peaks), 300)

# 2. Stipulated Combinatorial Model (Preserves 99% peak amplitude)
comp_peaks = target_peaks * 0.99 + np.random.normal(0, 0.02, 300)

(mse_means, mse_diffs, mse_bias, mse_loa_l, mse_loa_u, mse_pct_diff, mse_pct_bias) = compute_ba_statistics(mse_peaks, target_peaks, "MSE Model ($L_2$)")
(comp_means, comp_diffs, comp_bias, comp_loa_l, comp_loa_u, comp_pct_diff, comp_pct_bias) = compute_ba_statistics(comp_peaks, target_peaks, "Combinatorial Loss Model")
