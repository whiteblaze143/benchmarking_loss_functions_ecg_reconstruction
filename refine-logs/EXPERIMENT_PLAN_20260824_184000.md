# Experiment Plan: Complete 3-Architecture Factorial Parity (UNet vs MS-VAE vs ECG-AIM)

**Problem**: Establish a clean, balanced, and leak-free cross-architecture benchmark of loss function components by completing the remaining 37 factorial ECG-AIM models on available CPU compute (6 cores), achieving exact parity with the completed ~160 UNets and ~160 MS-VAEs.
**Method Thesis**: Architectural inductive biases (1D U-Net convolutional skip connections vs MS-VAE multiscale latent bottlenecks vs ECG-AIM spatial-temporal cross-attention) interact differently with loss components (spectral correlation, derivative L1, VCG physics); completing the full factorial grid provides the first fair, apples-to-apples 3-architecture evaluation across identical data splits and external clinical cohorts.
**Date**: 2026-08-24

## Experiment Blocks

### Block 1: 37-Model ECG-AIM Factorial Completion on 6-Core CPU
- **Claim Tested**: The remaining 37 ECG-AIM models (masks `1100013` to `1111114`, seed 42) train to convergence with identical checkpoint format, tensor schema, and loss tracking.
- **Why This Block Exists**: Closes the final gap in the 3-architecture registry, bringing ECG-AIM to 168 models alongside UNet (168) and MS-VAE (168).
- **Dataset / Split**: PTB-XL training (17,441 records) and validation (2,183 records) at 500 Hz (10s, 5,000 samples).
- **Compared Systems**: The 37 pending factorial masks (`1100013_s42` through `1111114_s42`).
- **Metrics**: Validation missing-lead Pearson correlation, validation reconstruction loss, gradient norm stability.
- **Setup Details**:
  - CPU execution: PyTorch with `taskset -c 0-5` (6 CPU cores allocated).
  - Multi-threading: `torch.set_num_threads(6)`, `OMP_NUM_THREADS=6`, `MKL_NUM_THREADS=6`.
  - Batch size: 32 (optimized for 6-core RAM throughput, RSS ~2.5 GiB).
  - Checkpoint verification: SHA-256 bound, registered directly to `results/checkpoint_store/catalog.sqlite`.
- **Success Criterion**: 37 / 37 checkpoints materialize with valid finite weights and registered metadata.
- **Priority**: **MUST-RUN**.

### Block 2: Cross-Architecture Main 48-Cell Matrix Comparison
- **Claim Tested**: Composite objective `1110000` (MSE + Correlation + Derivative L1) consistently outperforms Pure MSE (`1000000`) across all 3 architectures.
- **Why This Block Exists**: The core paper table (Table 1: 3 Architecture $\times$ Factorial Loss matrix).
- **Dataset / Split**: PTB-XL held-out test split (2,198 records).
- **Compared Systems**: 1D UNet, MS-VAE, and ECG-AIM across the 48 canonical factorial cells.
- **Metrics**: Missing-lead Pearson $r$, Normalized RMSE, Macro-averaged SNR, 5th percentile Pearson $r_{05}$.
- **Success Criterion**: $\Delta r > 0.04$ over pure MSE across all 3 architectures ($p < 0.001$).
- **Priority**: **MUST-RUN**.

### Block 3: External Multi-Dataset Blinded Delineation & Oracle (RDB & LUDB)
- **Claim Tested**: Enhanced loss terms reduce external boundary localization error below AAMI 20 ms tolerance across architectures.
- **Why This Block Exists**: Defends clinical validity on independent clinical cohorts with expert annotations.
- **Dataset / Split**: RDB (2,398 records) and LUDB (200 records).
- **Compared Systems**: Top-5 factorial checkpoints per architecture vs baseline `1000000`.
- **Metrics**: 20 ms tolerance Boundary $F_1$, Boundary MAE (ms), J-point voltage error ($\mu\text{V}$).
- **Success Criterion**: Boundary MAE $\le 15.0\text{ ms}$ on missing precordials for top ECG-AIM models.
- **Priority**: **MUST-RUN**.

### Block 4: Diagnostic Utility & Interval Calibration (QTc / LVH / Arrhythmia)
- **Claim Tested**: Reconstructed precordial waveforms preserve scalar interval biomarkers without introducing systematic bias.
- **Why This Block Exists**: Clinical safety demonstration.
- **Dataset / Split**: PTB-XL clinical test cohort.
- **Compared Systems**: UNet vs MS-VAE vs ECG-AIM under `1110000` vs `1000000`.
- **Metrics**: $\Delta\text{QTc}$ Bland-Altman limits of agreement, Sokolow-Lyon LVH sensitivity/specificity, AFib detection AUROC.
- **Success Criterion**: $\Delta\text{QTc}$ 95% limits within $\pm 12\text{ ms}$; zero statistically significant bias ($p > 0.05$).
- **Priority**: **MUST-RUN**.

### Block 5: Multiplicity & Familywise Error Control
- **Claim Tested**: Observed gains remain statistically significant under 2,000 paired bootstrap resamples and Benjamini-Hochberg / Holm adjustments.
- **Why This Block Exists**: Methodological rigor required by top venues (NeurIPS / ICML / Nature BME).
- **Priority**: **MUST-RUN**.
