8.9 Remaining limits

## Cross-cohort transport among the 31 shared models

```{python}
#| label: threelead-cross-cohort
shared = (le.query("model_id != '__original__'")
          .merge(re.query("model_id != '__original__'"), on="model_id",
                 suffixes=("_ludb", "_rdb")))
shared_metrics = ["signal_pearson_p05", "signal_mse_p95",
                  "primary_mean_micro_f1_20ms"]
transport_rows = []
for metric in shared_metrics:
    pair = shared[[f"{metric}_ludb", f"{metric}_rdb"]].dropna()
    transport_rows.append({
        "metric": metric, "shared_models": len(pair),
        "Pearson": pair.iloc[:, 0].corr(pair.iloc[:, 1]),
        "Spearman": pair.iloc[:, 0].corr(pair.iloc[:, 1], method="spearman")})
display(pd.DataFrame(transport_rows))

fig = px.scatter(shared, x="primary_mean_micro_f1_20ms_ludb",
                 y="primary_mean_micro_f1_20ms_rdb", hover_name="model_id",
                 color="factorial_mask_ludb", trendline="ols",
                 title="Boundary-F1 transport across LUDB and RDB")
fig.show()
```

Boundary ranking transports moderately well: Spearman correlation is 0.736
across the 31 shared trained models. Waveform-tail ranking transports much less
well: Pearson-p05 Spearman is 0.300 and MSE-p95 Spearman is −0.026. Dataset
differences reorder models far more strongly for waveform fidelity than for
downstream delineation retention.

This comparison is conditional on promotion. The 31 RDB models are a selected
subset of the 123 LUDB candidates, so the correlation does not estimate
transport for the full architecture space and may be range-restricted.

## Retention relative to the measured-signal reference

```{python}
#| label: threelead-reference-gaps
reference_rows = []
for cohort, frame in [("LUDB", le), ("RDB", re)]:
    reference = frame.query("model_id == '__original__'").iloc[0]
    trained = frame.query("model_id != '__original__'")
    for metric in shared_metrics:
        direction = metric_direction(metric)
        best = trained.sort_values(metric, ascending=(direction == "min")).iloc[0]
        favorable_gap = ((reference[metric] - best[metric]) if direction == "min"
                         else (best[metric] - reference[metric]))
        reference_rows.append({"cohort": cohort, "metric": metric,
                               "reference": reference[metric],
                               "best_model": best.model_id,
                               "best_reconstruction": best[metric],
                               "favorable_gap_vs_reference": favorable_gap})
display(pd.DataFrame(reference_rows))
```

On RDB, the best reconstructed boundary result is 0.7404 versus 0.7430 on the
measured signal, a gap of 0.0026. On LUDB, the best reconstruction is 0.6302
versus 0.6938, a gap of 0.0636. The smaller RDB gap is encouraging for retaining
the downstream delineator's events, but does not mean the true waveform was
recovered: RDB signal Pearson p05 remains at most 0.638.

The measured-signal row is a protocol reference, not a trainable competitor.
Its Pearson of 1 and MSE of 0 are identities, while its boundary F1 is below 1
because the fixed delineator itself is imperfect. Boundary retention can
approach the reference even when waveform fidelity remains limited.

## Oracle endpoint disagreement and Pareto selection

```{python}
#| label: threelead-oracle-pareto
oracle_focus = [c for c in [
    "metric.signal_pearson_p05", "metric.signal_mse_p95",
    "metric.boundary_voltage_abs_error_record_p95_mv",
    "metric.qrs_window_rmse_record_p95_mv",
    "metric.qrs_absolute_area_error_record_p95_mv_ms",
    "metric.t_window_rmse_record_p95_mv",
    "metric.t_absolute_area_error_record_p95_mv_ms",
    "metric.st_j_abs_error_record_p95_mv"] if c in oracle]
oracle_leaders = []
for metric in oracle_focus:
    best = oracle.sort_values(metric, ascending=(metric_direction(metric) != "max")).iloc[0]
    oracle_leaders.append({"metric": metric, "leader": best.model_id,
                           "value": best[metric]})
display(pd.DataFrame(oracle_leaders))

ranks = pd.DataFrame({"model_id": oracle.model_id})
for metric in oracle_focus:
    ranks[metric] = oracle[metric].rank(
        ascending=(metric_direction(metric) != "max"), method="min")
ranks["mean_endpoint_rank"] = ranks[oracle_focus].mean(axis=1)
display(ranks.sort_values("mean_endpoint_rank"))
```

Different checkpoints lead signal correlation, boundary-voltage error, QRS
window error, QRS area, T-window error, T area, and ST/J error. No checkpoint is
the oracle winner on every endpoint. Mean rank is a diagnostic summary, not a
validated clinical utility function or substitute for a predeclared hierarchy.
