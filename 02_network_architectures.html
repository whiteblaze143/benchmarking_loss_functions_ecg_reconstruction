Reconstructing a full 12-lead clinical ECG array \(\mathbf{Y} \in \mathbb{R}^{12 \times T}\) from a reduced input subset \(\mathbf{X} \in \mathbb{R}^{C_{in} \times T}\) (where \(C_{in} \in \{1, 3\}\)) requires a deep neural network capable of capturing both local temporal morphology (e.g., sharp QRS spikes) and cross-lead spatial correlations (e.g., precordial progression).

This chapter details the primary deep learning architectures evaluated in this handbook: 1. 1D U-Net with Multi-Scale Skip Connections 2. 1D Residual Networks (ResNet-1D) 3. Conformer-1D (Convolutional Transformer Hybrid)

4.1 Mathematical Foundations of 1D Signal Operations

4.1.1 1. 1D Cross-Correlation Convolution

For a 1D sequence tensor \(x \in \mathbb{R}^{C_{in} \times L_{in}}\), a 1D convolutional layer with kernel weight tensor \(W \in \mathbb{R}^{C_{out} \times C_{in} \times K}\) computes:

\[y[c_{out}, t] = b[c_{out}] + \sum_{c_{in}=0}^{C_{in}-1} \sum_{k=0}^{K-1} W[c_{out}, c_{in}, k] \cdot x[c_{in}, t \cdot s + k \cdot d - p]\]

where \(K\) is kernel size, \(s\) is stride, \(p\) is padding, and \(d\) is dilation rate.

The output length \(L_{out}\) is given by: \[L_{out} = \left\lfloor \frac{L_{in} + 2p - d(K-1) - 1}{s} + 1 \right\rfloor\]

For ECG signals sampled at \(f_s = 500\text{ Hz}\), a kernel size of \(K = 15\) with padding \(p = 7\) covers a receptive field of \(\frac{15}{500} = 30\text{ ms}\), corresponding precisely to the duration of a typical QRS onset slope.

4.1.2 2. Transposed 1D Convolution (Fractionally Strided Upsampling)

To upsample feature maps in the decoder, Transposed 1D Convolution reverses the spatial reduction of strided convolutions:

\[L_{out} = (L_{in} - 1) \cdot s - 2p + d(K-1) + \text{output\_padding} + 1\]

When \(s = 2\), \(K = 2\), \(p = 0\), the sequence length doubles (\(L_{out} = 2 L_{in}\)), allowing the network to recover fine temporal resolution.

4.2 1D U-Net Architecture Implementation

The 1D U-Net uses a symmetric contracting encoder path (which compresses temporal resolution while building high-level cardiac feature representations) and an expanding decoder path (which restores sequence length). Residual skip connections concatenate encoder feature maps directly with upsampled decoder features, preventing loss of high-frequency QRS details.

       Encoder (Contracting)                      Decoder (Expanding)
  Input (3, L) ────► [DoubleConv] ───────────────► Cat ─► [DoubleConv] ─► Output (12, L)
                          │                         ▲
                          ▼ MaxPool(2)              │ ConvTranspose(2)

4.2.1 PyTorch Implementation & Tensor Flow Breakdown

Code 
import torch
import torch.nn as nn
import torch.nn.functional as F

class DoubleConv1D(nn.Module):
    """
    Two consecutive 1D Conv layers, each followed by BatchNorm and LeakyReLU.
    Preserves sequence length by setting padding = kernel_size // 2.
    """
    def __init__(self, in_channels, out_channels, kernel_size=15):
        super().__init__()
        padding = kernel_size // 2
        self.double_conv = nn.Sequential(
            nn.Conv1d(in_channels, out_channels, kernel_size=kernel_size, padding=padding, bias=False),
            nn.BatchNorm1d(out_channels),
            nn.LeakyReLU(0.2, inplace=True),
            nn.Conv1d(out_channels, out_channels, kernel_size=kernel_size, padding=padding, bias=False),
            nn.BatchNorm1d(out_channels),
            nn.LeakyReLU(0.2, inplace=True)
        )

    def forward(self, x):
        return self.double_conv(x)

class UNet1DECG(nn.Module):
    """
    1D U-Net for 12-Lead ECG Reconstruction.
    
    Args:
        in_channels (int): Number of input leads (e.g., 3 for patch or 1 for Lead I)
        out_channels (int): Number of target leads (12 for full array)
        base_filters (int): Filter count at first layer (doubles each encoder stage)
    """
    def __init__(self, in_channels=3, out_channels=12, base_filters=64):
        super().__init__()
        # Encoder (Contracting Path)
        self.inc = DoubleConv1D(in_channels, base_filters)
        self.down1 = nn.Sequential(nn.MaxPool1d(2), DoubleConv1D(base_filters, base_filters * 2))
        self.down2 = nn.Sequential(nn.MaxPool1d(2), DoubleConv1D(base_filters * 2, base_filters * 4))
        self.down3 = nn.Sequential(nn.MaxPool1d(2), DoubleConv1D(base_filters * 4, base_filters * 8))

        # Bottleneck
        self.bottleneck = DoubleConv1D(base_filters * 8, base_filters * 8)

        # Decoder (Expanding Path with Transposed Convolution)
        self.up1 = nn.ConvTranspose1d(base_filters * 8, base_filters * 4, kernel_size=2, stride=2)
        self.conv_up1 = DoubleConv1D(base_filters * 8, base_filters * 4)

        self.up2 = nn.ConvTranspose1d(base_filters * 4, base_filters * 2, kernel_size=2, stride=2)
        self.conv_up2 = DoubleConv1D(base_filters * 4, base_filters * 2)

        self.up3 = nn.ConvTranspose1d(base_filters * 2, base_filters, kernel_size=2, stride=2)
        self.conv_up3 = DoubleConv1D(base_filters * 2, base_filters)

        # Final 1x1 Spatial Projection to 12 Clinical Leads
        self.outc = nn.Conv1d(base_filters, out_channels, kernel_size=1)

    def forward(self, x):
        # Encoder
        x1 = self.inc(x)        # Shape: (B, 64, L)
        x2 = self.down1(x1)     # Shape: (B, 128, L/2)
        x3 = self.down2(x2)     # Shape: (B, 256, L/4)
        x4 = self.down3(x3)     # Shape: (B, 512, L/8)

        # Bottleneck
        b = self.bottleneck(x4) # Shape: (B, 512, L/8)

        # Decoder Stage 1 (Concatenate with x3)
        u1 = self.up1(b)        # Shape: (B, 256, L/4)
        x = torch.cat([u1, x3], dim=1) # Shape: (B, 512, L/4)
        x = self.conv_up1(x)    # Shape: (B, 256, L/4)

        # Decoder Stage 2 (Concatenate with x2)
        u2 = self.up2(x)        # Shape: (B, 128, L/2)
        x = torch.cat([u2, x2], dim=1) # Shape: (B, 256, L/2)
        x = self.conv_up2(x)    # Shape: (B, 128, L/2)

        # Decoder Stage 3 (Concatenate with x1)
        u3 = self.up3(x)        # Shape: (B, 64, L)
        x = torch.cat([u3, x1], dim=1) # Shape: (B, 128, L)
        x = self.conv_up3(x)    # Shape: (B, 64, L)

        # Output projection
        out = self.outc(x)      # Shape: (B, 12, L)
        return out

4.4 ResNet-1D Architecture (Residual Bottlenecks)

While U-Net uses skip connections across resolution levels, ResNet-1D introduces residual blocks within each resolution stage: \[\mathbf{y} = \mathcal{F}(\mathbf{x}, \{W_i\}) + \mathbf{x}\]

This identity shortcut allows gradients to flow directly through the network during backpropagation, eliminating vanishing gradients when scaling depth.

Code 
class ResBlock1D(nn.Module):
    """
    Residual Block for 1D Signal Processing.
    """
    def __init__(self, channels):
        super().__init__()
        self.conv1 = nn.Conv1d(channels, channels, kernel_size=7, padding=3, bias=False)
        self.bn1 = nn.BatchNorm1d(channels)
        self.relu = nn.ReLU(inplace=True)
        self.conv2 = nn.Conv1d(channels, channels, kernel_size=7, padding=3, bias=False)
        self.bn2 = nn.BatchNorm1d(channels)

    def forward(self, x):
        residual = x
        out = self.relu(self.bn1(self.conv1(x)))
        out = self.bn2(self.conv2(out))
        out += residual  # Identity shortcut addition
        return self.relu(out)

```{python}
    """
    Residual Block for 1D Signal Processing.
    """
    def __init__(self, channels):
        super().__init__()
        self.conv1 = nn.Conv1d(channels, channels, kernel_size=7, padding=3, bias=False)
        self.bn1 = nn.BatchNorm1d(channels)
        self.relu = nn.ReLU(inplace=True)
        self.conv2 = nn.Conv1d(channels, channels, kernel_size=7, padding=3, bias=False)
        self.bn2 = nn.BatchNorm1d(channels)

    def forward(self, x):
        residual = x
        out = self.relu(self.bn1(self.conv1(x)))
        out = self.bn2(self.conv2(out))
        out += residual  # Identity shortcut addition
        return self.relu(out)
```
