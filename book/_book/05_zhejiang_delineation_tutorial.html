6.1 Why this chapter appears before model results

This chapter is an input-data audit, not evidence that one reconstruction loss is clinically superior. The local Zhejiang collection can support a useful external morphology benchmark, but the current result table contains only a ground-truth ceiling row. It therefore cannot yet estimate an MSE-versus-MMD contrast. Keeping that distinction visible prevents an available dataset from being mistaken for a completed experiment.

The audit below reads the files in data/zhejiang directly. It establishes what is physically present, checks signal-label pairing and mask integrity, and states the provenance information that is still missing. Later chapters may cite this cohort only within those bounds.

Code 
from pathlib import Path
import hashlib
import pickle

import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
from IPython.display import Markdown, display

REPO = Path("..").resolve()
DATA_ROOT = REPO / "data" / "zhejiang"
ECG_ROOT = DATA_ROOT / "ecg"
LABEL_ROOT = DATA_ROOT / "label"
RESULT_CSV = REPO / "results" / "zhejiang_benchmark" / "zhejiang_delineation_evaluation.csv"

LEADS = ("I", "II", "III", "aVR", "aVL", "aVF", "V1", "V2", "V3", "V4", "V5", "V6")

def sha256_file(path, chunk_bytes=1024 * 1024):
    digest = hashlib.sha256()
    with path.open("rb") as handle:
        for chunk in iter(lambda: handle.read(chunk_bytes), b""):
            digest.update(chunk)
    return digest.hexdigest()

if not ECG_ROOT.is_dir() or not LABEL_ROOT.is_dir():
    raise FileNotFoundError(
        "The Zhejiang audit requires data/zhejiang/ecg and data/zhejiang/label."
    )

6.2 Physical inventory and pairing

Signal filenames follow <record_id>_<lead>.pkl; label filenames follow <record_id>.pkl. The audit treats those filenames as identifiers—it does not infer patient independence, acquisition site, diagnosis, units, duration, or sampling frequency from the directory name.

signal_files = sorted(ECG_ROOT.glob("*.pkl"))
label_files = sorted(LABEL_ROOT.glob("*.pkl"))

signal_rows = []

    record_id, sep, lead = stem.rpartition("_")

        "lead": lead if sep else "UNPARSED",

signal_index = pd.DataFrame(signal_rows)
label_ids = {path.stem for path in label_files}
signal_ids = set(signal_index["record_id"])
lead_counts = signal_index.groupby("record_id")["lead"].nunique()

inventory = pd.DataFrame([
    ("Signal files", len(signal_files)),
    ("Label files", len(label_files)),
    ("Unique signal record IDs", len(signal_ids)),
    ("Signal IDs with a label", len(signal_ids & label_ids)),

6.3 Array and annotation integrity

Every label array is loaded below. Signal integrity is checked for every lead file as well, so the displayed counts describe the local corpus rather than a convenience sample. Mask values are audited against the observed convention 0=background, 1=P, 2=QRS, and 3=T; this convention is an interpretation used by the evaluator and still needs an authoritative data dictionary.

Code 
signal_audit = []
for path in signal_files:
    with path.open("rb") as handle:
        array = np.asarray(pickle.load(handle))
    signal_audit.append({
        "samples": int(array.size),
        "ndim": int(array.ndim),
        "dtype": str(array.dtype),
        "finite": bool(np.isfinite(array).all()),

mask_audit = []
mask_class_counts = {class_id: 0 for class_id in (0, 1, 2, 3)}
unexpected_mask_values = set()

    with path.open("rb") as handle:
        mask = np.asarray(pickle.load(handle))
    values, counts = np.unique(mask, return_counts=True)
    for value, count in zip(values, counts):
        numeric_value = float(value)
        if numeric_value in mask_class_counts:

The plot uses the native sample index. A time axis, millivolt axis, or resampling operation would require verified acquisition metadata; the evaluator currently assumes 2,000 Hz, but that assumption is not documented by a local source file. The visualization therefore makes only the defensible claim that the signal and categorical mask are sample-aligned.

6.6 Generation-bound evaluation protocol

A defensible external delineation result must bind each row to the exact model generation. For every checkpoint, the evaluation artifact should record:

  1. model ID, mask, seed, checkpoint SHA-256, source-bundle SHA-256, training contract, and checkpoint byte count;
  2. a content digest for the Zhejiang signal and label inputs, plus documented units and acquisition sampling rate;
  3. the input-lead mapping and all preprocessing, including any resampling and annotation-index transform;
  4. per-record and per-wave Dice, onset error, offset error, detection failures, and paired-record coverage—not only an aggregate mean;
  5. paired uncertainty across records and multiplicity control for the predeclared factorial contrasts;
  6. a failure ledger for missing waves, unusable records, and numerical errors.

The storage layer described later in the book already supports the first requirement: an archived checkpoint is materialized by exact content hash for inference and removed from the local cache afterward. The current Zhejiang evaluator does not yet satisfy the remaining provenance and coverage requirements and its one-row output must remain a pipeline check.

6.7 Interpretation boundary

The local files establish a paired 12-lead signal-and-mask corpus with internally consistent array structure. They do not, by themselves, establish cohort independence, diagnostic labels, RVOT/LVOT composition, sampling rate, voltage units, or licensing terms. Those facts require an authoritative README, paper, or data dictionary. Until model rows are generated under the protocol above, this chapter supports dataset readiness work—not a claim that MMD, MSE, or any other objective better preserves clinical morphology.
