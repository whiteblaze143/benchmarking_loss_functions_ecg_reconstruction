7.1 Protocol boundary and dataset identity

This evaluation tests the 60 completed one-lead ECG-AIM spatial models on the external Russian Database (RDB) cohort.

RDB provides ground-truth clinical delineations for six distinct cardiac fiducials: - P-wave onset (P_{\text{onset}}) and offset (P_{\text{offset}}) - QRS-complex onset (QRS_{\text{onset}}) and offset (QRS_{\text{offset}}) - T-wave onset (T_{\text{onset}}) and offset (T_{\text{offset}})

No peak fiducials exist in the annotation protocol; hence, peak-based timing is not inferred or interpolated.

7.3.1 Boundary-Specific Insights:

  • QRS Fiducials are Highly Preserved: Both QRS_{\text{onset}} and QRS_{\text{offset}} achieve 0.78–0.86 F1, reflecting steep, high-frequency voltage transitions that are robust to reconstruction blur.
  • P-Wave Boundaries Suffer Major Degradation: P_{\text{onset}} (0.45–0.54 F1) and P_{\text{offset}} (0.50–0.58 F1) exhibit substantial localization error due to low atrial depolarization amplitudes.
  • No Uniform Architectural Separation: Spatial variants like E_1 do not pull away from A_0 across boundaries; differences are confined to narrow \pm 0.01–0.02 bands.

## External spatial control transport testing: Where internal gains fail

To formally test why $E_1$ cannot be promoted as an improved universal base, we compute matched paired contrasts on the external RDB benchmark:

```{python}
#| label: onelead-rdb-transport-forest
ext_matrix = full_evaluations.pivot_table(
    index=["factorial_mask", "input_lead"], columns="variant",
    values=["primary_mean_micro_f1_20ms", "primary_signal_pearson_p05"]
)

transport_tests = []
for metric, metric_name in [("primary_mean_micro_f1_20ms", "Boundary F1 20ms"),
                            ("primary_signal_pearson_p05", "Signal Pearson P05")]:
    for cand, ref, label in [
        ("e1_panorama_film", "pg1_permuted_geometry", "E1 vs Permuted Geometry"),
        ("e1_panorama_film", "cm1_capacity_matched", "E1 vs Capacity Control"),
        ("e1_panorama_film", "a0", "E1 vs Baseline A0"),
        ("b1_panorama", "a0", "B1 vs Baseline A0"),
    ]:
        diffs = ext_matrix[(metric, cand)] - ext_matrix[(metric, ref)]
        diffs = diffs.dropna()
        n = len(diffs)
        mean_d = float(diffs.mean())
        std_d = float(diffs.std(ddof=1)) if n > 1 else 0.0
        t_stat, p_val = stats.ttest_1samp(diffs, 0.0) if n > 1 and std_d > 0 else (np.nan, np.nan)
        transport_tests.append({
            "metric": metric_name, "contrast": label,
            "mean_delta": mean_d, "std_delta": std_d,
            "ci_low": mean_d - 1.96 * (std_d / np.sqrt(n)),
            "ci_high": mean_d + 1.96 * (std_d / np.sqrt(n)),
            "p_value": p_val,
            "wins": int((diffs > 0).sum()), "losses": int((diffs < 0).sum()),
        })

df_ext_tests = pd.DataFrame(transport_tests)
display(df_ext_tests)

fig_ext_forest = go.Figure()
for idx, row in df_ext_tests.iterrows():
    fig_ext_forest.add_trace(go.Scatter(
        x=[row["mean_delta"]], y=[f"{row['metric']} · {row['contrast']}"],
        error_x=dict(type="data", symmetric=False,
                     array=[row["ci_high"] - row["mean_delta"]],
                     arrayminus=[row["mean_delta"] - row["ci_low"]],
                     width=6, thickness=2),
        mode="markers", marker=dict(size=10, color="teal" if row["mean_delta"] > 0 else "crimson"),
        name=row["contrast"],
        hovertext=f"Mean Δ: {row['mean_delta']:.4f}<br>95% CI: [{row['ci_low']:.4f}, {row['ci_high']:.4f}]<br>p-value: {row['p_value']:.4f}<br>Wins: {row['wins']}/6",
        hoverinfo="text"
    ))

fig_ext_forest.add_vline(x=0, line_dash="dash", line_color="black")
fig_ext_forest.update_layout(
    title="External RDB Matched Spatial Contrasts Forest Plot (95% CI)",
    xaxis_title="External Improvement (Δ on RDB)",
    yaxis=dict(autorange="reversed"),
    showlegend=False, height=500
)
fig_ext_forest.show()
```

### Critical Transport Findings:
1. **$E_1$ Geometry Advantage Reverses Externally**:
   - For Boundary F1, $E_1 - PG_1$ averages +0.007 ($p = 0.35$), with losses in 2 out of 6 cells.
   - For Signal Pearson P05, $E_1 - PG_1$ averages **-0.004** ($p = 0.70$), with 3 losses and 3 wins.
2. **$E_1$ vs Capacity Control ($CM_1$) Fails Significance**:
   - Boundary F1: $p = 0.44$; Signal P05: $p = 0.84$.
3. **Conclusion**: While true geometry provides a statistically significant +0.0063 gain on internal validation data, this advantage dissipates and reverses sign across external RDB cells. **$E_1$ is therefore not an improved universal base.**
