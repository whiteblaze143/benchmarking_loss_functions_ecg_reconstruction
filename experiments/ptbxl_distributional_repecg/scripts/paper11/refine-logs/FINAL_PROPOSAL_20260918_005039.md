# Final Proposal: Paper 11 — Predictive State Compression for Ordered ECG Beats

Paper 11 asks whether a finite state computed solely from prior ordered beats predicts the next beat better than matched non-predictive alternatives. This is an empirical predictive-compression claim, not an epsilon-machine or biological-causality claim.

The existing BCE-only GRU grid and record-averaged Phase-KME inputs are invalid for that question. The replacement uses a causal-prefix encoder, categorical state posterior, next-beat decoder, and diagnosis readout. It must pass finite-HMM recovery plus wrong-future and IID falsification before any clinical pilot.
