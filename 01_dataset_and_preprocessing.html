13.1 The contract actually used by training

The active reconstruction study reads precomputed PTB-XL tensors from data/ptb_xl/tensors/{train,val,test}. Each file is named by ECG record ID and contains a 12-by-5,000 floating-point array in canonical lead order. The model observes I, II, and V2—indices [0, 1, 7]—and reconstructs the nine remaining leads. Earlier text in this chapter incorrectly selected II, V1, and V5; that would define a different inverse problem and has been removed.

The content-pinned training contract declares 500 Hz, 10 seconds, mV, no normalization, train folds 1–8, validation fold 9, test fold 10, and batch size 1,024 for the running generation. “No normalization” and “no bandpass” mean the tensor values are passed to the model as stored; the Fourier/filter example later in this chapter is exploratory and is not a production transform.

13.2 Canonical lead geometry

The stored order is

[I,II,III,aVR,aVL,aVF,V1,V2,V3,V4,V5,V6].

The limb leads are linear combinations of three electrode potentials:

I=\Phi_{LA}-\Phi_{RA},\qquad II=\Phi_{LL}-\Phi_{RA},\qquad III=II-I,

aVR=-\frac{I+II}{2},\qquad aVL=I-\frac{II}{2},\qquad aVF=II-\frac{I}{2}.

These identities motivate cross-lead residual checks, but digitized clinical leads need not satisfy them to machine precision because of acquisition, filtering, quantization, timing, and export behavior. The precordial leads V1–V6 are separate chest-electrode measurements relative to a central terminal; they cannot be exactly derived from I and II.

The model observes I, II, and V2. The choice combines two limb views with one early precordial view; it is a study design choice, not a claim that this is the optimal sensor placement or that a smartwatch records all three.

13.3 Executable dataset loader

The loader below mirrors the active tensor semantics: numeric record ordering, weights_only=True, float conversion, shape validation, no signal normalization, and selection of [0,1,7]. Padding to 5,120 is performed in the U-Net training/evaluation path, not persisted in these tensor files.

Code 
class PTBXLTensorDataset(Dataset):
    lead_names = ("I", "II", "III", "aVR", "aVL", "aVF", "V1", "V2", "V3", "V4", "V5", "V6")
    observed_indices = (0, 1, 7)

    def __init__(self, tensor_root, split):
        self.split = split
        self.files = sorted(
            (Path(tensor_root) / split).glob("*.pt"),
            key=lambda path: int(path.stem),
        )
        if not self.files:
            raise FileNotFoundError(f"No tensors found for split {split!r}")

    def __len__(self):
        return len(self.files)

    def __getitem__(self, index):
        path = self.files[index]
        target = torch.load(path, map_location="cpu", weights_only=True).float()
        if tuple(target.shape) != (12, 5000):
            raise ValueError(f"Expected [12,5000] at {path}, got {tuple(target.shape)}")
        if not torch.isfinite(target).all():
            raise ValueError(f"Non-finite tensor at {path}")
        observed = target[list(self.observed_indices)]
        return observed, target, int(path.stem)

13.5 Spectral audit of the stored signal

A periodogram is a record-level diagnostic, not proof of a universal “QRS band.” The example below uses Welch’s method on the named Lead I tensor. Spectral summaries depend on window, detrending, segment length, and any upstream acquisition filtering, so those choices remain visible.

Code 
fs = contract["preprocessing"]["sample_rate_hz"]
lead_i = target[0].numpy()
frequencies, power = signal.welch(
    lead_i, fs=fs, window="hann", nperseg=1000, noverlap=500, detrend="constant"
)
fig = go.Figure(go.Scatter(

13.6 Filtering demonstration—not the training transform

Zero-phase forward-backward filtering applies a causal filter in both directions, canceling net phase while squaring its magnitude response. It can still change peak amplitudes, boundary shapes, edge samples, and noise content. The comparison below is therefore a sensitivity illustration only. The content-pinned checkpoints were trained on the unfiltered stored tensors, and filtered signals must not be substituted at inference without a separately trained/evaluated contract.

Code 
sos = signal.butter(3, [0.5, 45.0], btype="bandpass", fs=fs, output="sos")

13.7 Provenance and reconstruction boundary

The live tensor audit in the opening chapter pairs tensors back to raw 500 Hz WFDB records and verifies split membership, shapes, finite values, content roots, and sample agreement. The authoritative release metadata and local contract—not this plotting code—define units and sample rate. A downstream evaluator must reject a model when any of the following differ from its sidecar:

  1. lead order or observed indices;
  2. sampling rate, duration, units, scaling, filtering, or normalization;
  3. split record/patient membership or byte-content roots;
  4. padding/cropping and acquired-lead pass-through behavior;
  5. source bundle, state schema, or checkpoint digest.

This contract is what makes archived per-model inference meaningful: materializing the exact bytes is necessary, but those bytes are usable only with the exact preprocessing and lead semantics recorded alongside them.
