convergence["configuration"] = (convergence.run_name
    .str.replace(r"^conv(?:10|15)e_", "", regex=True)
    .str.replace(r"_s\d+_l[01]$", "", regex=True))

    id_vars=["configuration", "observed_lead", "expected_epochs", "run_name"],
    value_vars=trajectory_metrics, var_name="metric", value_name="value").dropna()

               .expected_epochs.nunique().loc[lambda x: x == 2].index)
trajectory = trajectory.set_index(["configuration", "observed_lead", "metric"])
trajectory = trajectory.loc[trajectory.index.isin(matched_ids)].reset_index()
fig = px.line(trajectory, x="expected_epochs", y="value", color="configuration",
              line_dash="observed_lead", facet_col="metric", facet_col_wrap=2,
              markers=True, hover_name="run_name",
              title="Matched convergence trajectories")
fig.update_xaxes(dtick=5)
fig.update_layout(height=1100)
fig.show()

P/T and boundary trajectories remain steep from epochs 10 to 15, whereas QRS is comparatively flat. This visualizes why fixed short budgets bias model selection toward fast-converging configurations and why horizon matching is a required control.


The wavelet branch produces the largest and most coherent effect, concentrated
on P and T. SSL is visibly lead-dependent. The phase-view contrast is small.
E1 contains only lead II because the matched lead-I cell failed, so its panel

This forest preserves native metric direction: higher is favourable for AUROC,
AUPRC, correlations and concordance; lower is favourable for Brier, log loss,

effect because that would mix discrimination, calibration, and milliseconds.

## Decision dashboard

| Decision | Evidence visible here | Current action |
|---|---|---|
| Promote a wavelet mechanism | coherent P/T gains and longer-horizon improvement | yes, for replicated/external testing |
| Claim an SSL main effect | lead-dependent screen; missing matched 15-epoch cell | no |
| Replace A0 with E1 | internal effect fails consistent external transport | no |
| Select one universal checkpoint | endpoint and cohort leaders disagree | no; retain Pareto candidates |
| Use latent probe clinically | weak comparator and no external calibration | no |
| Use latent outlier for QC research | held-out internal association | candidate for external calibration |

The dashboard is a decision aid over stored evidence. It does not create new
independent samples or repair missing seeds.
