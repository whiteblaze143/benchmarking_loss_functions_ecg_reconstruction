# Experiment Plan: Generation-Bound External Delineation Watcher

**Problem**: Evaluate every compatible checkpoint from the 480-model fixed-MCMA factorial grid on external delineation datasets without competing with GPU training or losing model-generation identity.
**Method Thesis**: Loss effects must be judged on endpoint-specific, per-record external morphology evidence; LUDB is the documented delineation benchmark, while ISP and Zhejiang remain explicitly exploratory until their local provenance and units are resolved.
**Date**: 2026-08-01

## Planning Gate

- **Stable thesis**: the contribution is an endpoint-aware factorial benchmark, not a predetermined composite-loss winner.
- **Dominant contribution**: five binary loss effects plus categorical MMD-kernel contrasts within one fixed MCMA architecture, with exact checkpoint/source/data/evaluator binding.
- **Complexity rejected**: no new generator, learned evaluator, GPU evaluation queue, pooled cross-dataset score, or hidden unit normalization.
- **Reviewer concerns addressed here**: external adapter correctness, delineator ceiling, per-record coverage, generation aliasing, and whether evaluation can keep pace safely.
- **Frontier primitive**: absent and unnecessary.

## Claim Map

| Claim | Why It Matters | Minimum Convincing Evidence | Linked Blocks |

## Experiment Blocks

### B0: External detector ceiling and adapter audit

- **Claim tested**: the evaluation stack can detect annotated morphology on source waveforms before judging reconstructions.
- **Datasets**: 199 locally complete LUDB waveforms; ISP 403 train + 72 test records; Zhejiang 334 records.
- **Metrics**: per-boundary event counts, one-to-one F1, timing error, P/QRS/T Dice, detector success/failure.
- **Setup**: source signal passed to the same NeuroKit DWT delineator; nine missing-lead positions only.
- **Success criterion**: artifacts complete with explicit failure denominators and no numerical or identity failures.
- **Failure interpretation**: low ceiling limits model-result interpretation and triggers detector/adapter review.
- **Priority**: MUST-RUN.

### B1: Per-checkpoint external delineation

- **Claim tested**: compatible factorial checkpoints differ in localized morphology preservation.
- **Compared systems**: every database-backed checkpoint compatible with training contract `factorial-v4-content-pinned-20260731`.
- **Metrics**: per-record/per-lead onset and offset F1, micro/macro F1, timing MAE/median/p95, Dice, detector coverage.
- **Identity**: model ID, mask, seed, checkpoint SHA-256/bytes, source-bundle SHA-256, dataset tree SHA-256, evaluator SHA-256.
- **Checkpoint selection**: training-selected validation checkpoint only; no external-label tuning.
- **Success criterion**: every compatible checkpoint has atomic artifacts for all three datasets and zero retained private-cache bytes.
- **Failure interpretation**: bounded two-attempt evaluator errors remain visible and cannot be silently converted into completions.
- **Priority**: MUST-RUN.

### B2: External preprocessing sensitivity and evidence tiers

- **LUDB**: documented 500 Hz/mV; eligible for confirmatory delineation analysis.
- **ISP**: header-declared 1000 Hz and nonstandard `mkv`; evaluated after polyphase 1000→500 Hz and explicit provisional `÷1000 → mV`.
- **Zhejiang**: native 20,000→5,000 sample mapping and explicit provisional `÷1000 → mV`; source rate/unit/class documentation unresolved.
- **Success criterion**: assumptions are embedded in every result contract and ISP/Zhejiang remain exploratory.
- **Failure interpretation**: authoritative metadata that contradict an adapter requires a new evaluator generation, not relabeling old rows.
- **Priority**: MUST-RUN integrity gate.

### B3: Complete-grid factorial inference

- **Claim tested**: binary loss components and MMD kernels have reproducible external effects.
- **Analysis**: seed-blocked main effects, categorical kernel contrasts, prespecified interactions, paired record uncertainty, multiplicity control.
- **Gate**: all 160 masks in seeds 42, 200, and 201, complete LUDB artifacts, admissible checkpoint identities, no unresolved model failures.
- **Priority**: MUST-RUN after execution completeness.

## Compute and Safety Budget

- GPU use: forbidden; production launches with `CUDA_VISIBLE_DEVICES=''`.
- CPU affinity: cores 4–5 only; two delineation workers maximum.
- Scheduling: `nice -n 19`, idle-class `ionice -c 3`.
- Thread caps: Torch, OpenMP, MKL, OpenBLAS, and NumExpr limited to one thread/process.
- Resource gates: wait above 6.5 one-minute load or below 4 GiB available memory.
- Checkpoint memory/disk: one exact generation materialized at a time in a private cache, then pruned to zero.
- Poll cadence: 20 minutes only after the compatible cohort is caught up.
- Biggest bottleneck: DWT delineation over nine leads × 1,008 external records per checkpoint; slowness is accepted to protect training.

## Risks and Mitigations

- **Unresolved ISP/Zhejiang provenance**: preserve exploratory evidence labels and immutable adapter descriptions.
- **Detector bias**: compute a source-signal ceiling using the identical detector.
- **Double event matching**: use monotonic one-to-one maximum-cardinality matching.
- **Observed-lead inflation**: primary artifacts default to the nine missing leads.
- **OOM/resource contention**: CPU-only affinity, two-worker ceiling, memory/load gates, low priority, bounded dataset/model memory.
- **Checkpoint aliasing**: intersect compatibility audit with SQLite identity and verify SHA-256 after materialization.
- **Partial writes**: atomic CSV/JSON replacement and per-model status metadata.
- **Permanent evaluator errors**: maximum two attempts, explicit error type/message, no silent fallback to the target waveform.
