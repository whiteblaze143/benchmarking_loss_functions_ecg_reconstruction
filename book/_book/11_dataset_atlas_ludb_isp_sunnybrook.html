5  Dataset Atlas: LUDB, ISP, and Sunnybrook

  • Show All Code
  • Hide All Code

LUDB, ISP, and Sunnybrook are complementary, not interchangeable. LUDB supplies dense lead-specific morphology annotations; ISP supplies interval targets for delineation; Sunnybrook supplies a small external set of fully measured clinical ECGs. A pooled “multi-dataset score” would erase those distinctions.

5.1 Provenance and governance ledger

The local files do not all have the same documentation status. LUDB is the public PhysioNet release v1.0.1, cited as Kalyakulina et al. with DOI 10.13026/eegm-h675, and is distributed under the Open Data Commons Attribution License v1.0. Its source states that 200 ten-second ECGs were collected in 2017–2018, annotated by cardiologists, with written consent and institutional review approval. EchoNext is a restricted PhysioNet resource; the local provenance identifies v1.1.1, while the canonical dataset record and version history are available under DOI 10.13026/2j37-ba56. It uses the PhysioNet Restricted Health Data License/Data Use Agreement 1.5.0; its source documents de-identification and IRB-approved retrospective use.

The ISP folder in this repository does not include a citation, version, license, data-use terms, or a source identifier. Its three class meanings and sampling rate therefore remain unknown in this book. Sunnybrook has a local METADATA.json and README but no accompanying license, cohort selection protocol, subject identifiers, consent/ethics statement, or distribution authority. Until those fields are supplied by the data owner, Sunnybrook is a local exploratory transfer set and ISP is a locally present delineation artifact—not a fully provenance-resolved public benchmark.

5.1.1 Reproducible local fingerprints

The following fingerprints identify the exact artifacts read by this book. A tree hash includes each relative path, file size, and file digest, so a renamed, added, removed, or changed record alters the result.

Code 
def file_sha256(path, chunk_size=8 * 1024 * 1024):
    digest = hashlib.sha256()
    with path.open("rb") as handle:
        for chunk in iter(lambda: handle.read(chunk_size), b""):
            digest.update(chunk)
    return digest.hexdigest()

def tree_sha256(root, patterns):
    files = sorted({
        path for pattern in patterns for path in root.rglob(pattern)
        if path.is_file()
    })
    digest = hashlib.sha256()
    total_bytes = 0
    for path in files:
        size = path.stat().st_size
        total_bytes += size
        digest.update(str(path.relative_to(root)).encode())
        digest.update(str(size).encode())
        digest.update(file_sha256(path).encode())
    return len(files), total_bytes, digest.hexdigest()

5.2.2 Demographics and diagnoses

The local headers yield 115 male and 85 female records. Age ranges from 11 to 90 years (mean 51.98, median 56). Diagnoses are overlapping free-text statements. Frequent statements include sinus rhythm (143), left ventricular hypertrophy (108), left atrial hypertrophy (102), normal electrical axis (75), left-axis deviation (66), incomplete right bundle-branch block (29), sinus bradycardia (25), and atrial fibrillation (15).

def parse_ludb_header(path):
    text = path.read_text()
    age = re.search(r"#<age>:\s*(\d+)", text)
    sex = re.search(r"#<sex>:\s*([MF])", text)
    statements = [
        line[1:].strip() for line in text.splitlines()
        if line.startswith("#") and not line.startswith("#<") and line[1:].strip()
    ]
    return {
        "age": int(age.group(1)) if age else np.nan,
        "sex": sex.group(1) if sex else "unknown",
        "statements": statements,
    }

5.2.3 Annotation grammar and counts

LUDB uses p for P peaks, N for QRS fiducials, t for T peaks, ( for onsets, and ) for offsets. Across the 2,400 lead-specific annotation streams, the local files contain 16,797 P peaks, 21,965 QRS markers, 19,661 T peaks, 58,321 onsets, and 58,423 offsets.

5.2.5 Diagnostics LUDB enables

For P, QRS, and T waves, report onset, peak, and offset error by lead. Matching must be beat-aware and limited to a physiologic window; unconstrained nearest-neighbor matching can pair adjacent cycles. Minimum outputs are sensitivity, positive predictive value, median/IQR/95th-percentile timing error, cycle-mismatch rate, error versus wave amplitude, and interval consistency across leads.

A reconstruction can have high sample correlation but erase a low-amplitude P wave or shift its boundary enough to corrupt PR measurement. LUDB is designed to reveal precisely that failure.

5.3 ISP delineation targets

5.3.1 Local data contract

The ISP CSVs contain 403 training and 72 test rows. Each row includes file_name, age, binary sex coding, and a serialized list of (class, onset, offset) intervals. The training split contains 14,148 intervals and the test split 2,558.

Training class counts are 4,312 / 5,048 / 4,788 for classes 0/1/2; test counts are 793 / 900 / 865. Median widths are 116/110/182 samples in training and 114/110/182 in test. The ordering suggests P/QRS/T-like triplets, but the semantic mapping must come from source documentation rather than inference from sequence alone.

The WFDB files are present and link one-to-one to the CSV file_name inside each split. Their headers declare 12 channels, 1,000 samples/s, approximately 9,998–10,000 samples, and a nonstandard unit token mkv. The numerical scale is consistent with microvolt-like values, but the book does not silently relabel mkv as µV without authoritative provenance.

def load_isp(split):
    path = ROOT / "data/isp_delineation_dataset" / f"{split}_isp_delineation_data.csv"
    frame = pd.read_csv(path)
    frame["intervals"] = frame.target.map(ast.literal_eval)
    frame["interval_count"] = frame.intervals.map(len)
    return frame

isp_train = load_isp("train")
isp_test = load_isp("test")

def summarize_isp(frame, split):
    intervals = [x for row in frame.intervals for x in row]

        "age_sd": frame.age.std(), "sex_0": (frame.sex == 0).sum(),

        "class_0": sum(x[0] == 0 for x in intervals),
        "class_1": sum(x[0] == 1 for x in intervals),

5.3.3 Interval integrity

Code 
def interval_audit(frame, split):
    lengths = isp_headers.loc[
        isp_headers.split == split
    ].set_index("file_name").samples
    rows = []
    for _, record in frame.iterrows():
        xs = record.intervals
        record_length = int(lengths.loc[record.file_name])
        rows.append({
            "file_name": record.file_name,
            "valid_class": all(x[0] in {0, 1, 2} for x in xs),
            "positive_width": all(x[1] < x[2] for x in xs),
            "within_window": all(0 <= x[1] < x[2] <= record_length for x in xs),
            "sorted": all(xs[j][1] <= xs[j + 1][1] for j in range(len(xs) - 1)),
        })
    return pd.DataFrame(rows)

5.4.3 Hyperfeatures and evidence level

The Philips XLI pipeline supplies global heart rate, PR/QRS/QT/QTc and axes; per-lead P/Q/R/S/T amplitudes; P/QRS/T durations; ST onset/midpoint/J+80/end/slope; measured-lead flags; and diagnostic statements. These are machine-derived reference features, not cardiologist-adjudicated truth.

The set includes sinus rhythms, atrial fibrillation/flutter, old inferior MI, chamber/conduction findings, poor R-wave progression, and a mislaced-lead warning. With only 20 records, these are cases for external stress testing, not stable prevalence or broad clinical-effect estimation.

5.4.4 Retained transients and robust analysis

The comprehensive package retains a 20.44 mV V5 transient in ECG010 and a 6.66 mV V4 transient in ECG008 without clipping. Final analyses should report median/IQR and per-record influence alongside means, with an explicitly labeled sensitivity analysis excluding flagged transients. Silent removal would hide a real robustness failure.

Provenance also notes an approximately 18 µV physical Einthoven residual. This is an empirical acquisition reference, not a universal “errors below 18 µV are perfect” threshold: lead-law residual and reconstruction error are different quantities.

Sunnybrook superclass endpoints use non-adjudicated Philips statement proxies. ECGFounder has probability-fidelity evaluation only because compatible 150-task labels are absent. Those qualifications must appear beside every result table, not only in an appendix.

## Provenance and governance ledger

The local files do not all have the same documentation status. LUDB is the public PhysioNet release v1.0.1, cited as Kalyakulina et al. with DOI [10.13026/eegm-h675], and is distributed under the Open Data Commons Attribution License v1.0. Its source states that 200 ten-second ECGs were collected in 2017–2018, annotated by cardiologists, with written consent and institutional review approval. EchoNext is a restricted PhysioNet resource; the local provenance identifies v1.1.1, while the canonical dataset record and version history are available under DOI [10.13026/2j37-ba56]. It uses the PhysioNet Restricted Health Data License/Data Use Agreement 1.5.0; its source documents de-identification and IRB-approved retrospective use.

  [10.13026/eegm-h675]: https://doi.org/10.13026/eegm-h675
  [10.13026/2j37-ba56]: https://doi.org/10.13026/2j37-ba56

The ISP folder in this repository does not include a citation, version, license, data-use terms, or a source identifier. Its three class meanings and sampling rate therefore remain unknown in this book. Sunnybrook has a local `METADATA.json` and README but no accompanying license, cohort selection protocol, subject identifiers, consent/ethics statement, or distribution authority. Until those fields are supplied by the data owner, Sunnybrook is a local exploratory transfer set and ISP is a locally present delineation artifact—not a fully provenance-resolved public benchmark.

### Reproducible local fingerprints

The following fingerprints identify the exact artifacts read by this book. A tree hash includes each relative path, file size, and file digest, so a renamed, added, removed, or changed record alters the result.

```{python}
#| label: dataset-provenance-hashes
#| tbl-cap: "SHA-256 fingerprints of the actual local dataset artifacts."
def file_sha256(path, chunk_size=8 * 1024 * 1024):
    digest = hashlib.sha256()
    with path.open("rb") as handle:
        for chunk in iter(lambda: handle.read(chunk_size), b""):
            digest.update(chunk)
    return digest.hexdigest()

def tree_sha256(root, patterns):
    files = sorted({
        path for pattern in patterns for path in root.rglob(pattern)
        if path.is_file()
    })
    digest = hashlib.sha256()
    total_bytes = 0
    for path in files:
        size = path.stat().st_size
        total_bytes += size
        digest.update(str(path.relative_to(root)).encode())
        digest.update(str(size).encode())
        digest.update(file_sha256(path).encode())
    return len(files), total_bytes, digest.hexdigest()

fingerprints = []
for dataset, root, patterns in [
    ("LUDB", ROOT / "data/ludb", ["*.hea", "*.dat", "*.atr_*", "README", "LICENSE.txt"]),
    ("ISP", ROOT / "data/isp_delineation_dataset", ["*.hea", "*.dat", "*.csv"]),
    ("Sunnybrook", ROOT / "data/sunnybrook_12_lead_ecg_samples", ["*.xml", "*.csv", "*.json", "*.md"]),
]:
    n_files, n_bytes, digest = tree_sha256(root, patterns)
    fingerprints.append({
        "dataset": dataset, "resolved_root": str(root.resolve()),
        "files_hashed": n_files, "bytes_hashed": n_bytes, "sha256_tree": digest,
    })

for name in [
```

## LUDB: lead-specific morphology ground truth

### Acquisition and inventory

The local LUDB copy contains 200 WFDB records. Every record has 12 leads, 5,000 samples at 500 Hz, ten seconds of duration, and physical units of mV. Each lead has a separate annotation stream, allowing a wave to be present or bounded differently across leads.

### Annotation grammar and counts

LUDB uses `p` for P peaks, `N` for QRS fiducials, `t` for T peaks, `(` for onsets, and `)` for offsets. Across the 2,400 lead-specific annotation streams, the local files contain 16,797 P peaks, 21,965 QRS markers, 19,661 T peaks, 58,321 onsets, and 58,423 offsets.


### Diagnostics LUDB enables

For P, QRS, and T waves, report onset, peak, and offset error by lead. Matching must be beat-aware and limited to a physiologic window; unconstrained nearest-neighbor matching can pair adjacent cycles. Minimum outputs are sensitivity, positive predictive value, median/IQR/95th-percentile timing error, cycle-mismatch rate, error versus wave amplitude, and interval consistency across leads.

A reconstruction can have high sample correlation but erase a low-amplitude P wave or shift its boundary enough to corrupt PR measurement. LUDB is designed to reveal precisely that failure.

## ISP delineation targets

### Local data contract

The ISP CSVs contain 403 training and 72 test rows. Each row includes `file_name`, age, binary sex coding, and a serialized list of `(class, onset, offset)` intervals. The training split contains 14,148 intervals and the test split 2,558.

Training class counts are 4,312 / 5,048 / 4,788 for classes 0/1/2; test counts are 793 / 900 / 865. Median widths are 116/110/182 samples in training and 114/110/182 in test. The ordering suggests P/QRS/T-like triplets, but the semantic mapping must come from source documentation rather than inference from sequence alone.

The WFDB files are present and link one-to-one to the CSV `file_name` inside each split. ### Interval integrity

```{python}
#| label: isp-integrity
def interval_audit(frame, split):
    lengths = isp_headers.loc[
        isp_headers.split == split
    ].set_index("file_name").samples
    rows = []
    for _, record in frame.iterrows():
        xs = record.intervals
        record_length = int(lengths.loc[record.file_name])
        rows.append({
            "file_name": record.file_name,
            "valid_class": all(x[0] in {0, 1, 2} for x in xs),
            "positive_width": all(x[1] < x[2] for x in xs),
            "within_window": all(0 <= x[1] < x[2] <= record_length for x in xs),
            "sorted": all(xs[j][1] <= xs[j + 1][1] for j in range(len(xs) - 1)),
        })
    return pd.DataFrame(rows)

pd.concat([
    interval_audit(isp_train, "train").assign(split="train"),
    interval_audit(isp_test, "test").assign(split="test"),
]).groupby("split").agg(
    records=("file_name", "count"),
    invalid_class=("valid_class", lambda x: (~x).sum()),
    invalid_width=("positive_width", lambda x: (~x).sum()),
    outside_window=("within_window", lambda x: (~x).sum()),
    unsorted=("sorted", lambda x: (~x).sum()),
)
```

### Hyperfeatures and evidence level

The Philips XLI pipeline supplies global heart rate, PR/QRS/QT/QTc and axes; per-lead P/Q/R/S/T amplitudes; P/QRS/T durations; ST onset/midpoint/J+80/end/slope; measured-lead flags; and diagnostic statements. These are machine-derived reference features, not cardiologist-adjudicated truth.

The set includes sinus rhythms, atrial fibrillation/flutter, old inferior MI, chamber/conduction findings, poor R-wave progression, and a mislaced-lead warning. With only 20 records, these are cases for external stress testing, not stable prevalence or broad clinical-effect estimation.

### Retained transients and robust analysis

The comprehensive package retains a 20.44 mV V5 transient in ECG010 and a 6.66 mV V4 transient in ECG008 without clipping. Final analyses should report median/IQR and per-record influence alongside means, with an explicitly labeled sensitivity analysis excluding flagged transients. Silent removal would hide a real robustness failure.

Provenance also notes an approximately 18 µV physical Einthoven residual. This is an empirical acquisition reference, not a universal “errors below 18 µV are perfect” threshold: lead-law residual and reconstruction error are different quantities.

Sunnybrook superclass endpoints use non-adjudicated Philips statement proxies. ECGFounder has probability-fidelity evaluation only because compatible 150-task labels are absent. Those qualifications must appear beside every result table, not only in an appendix.
