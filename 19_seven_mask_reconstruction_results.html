13.3 Factorial interpretation contract

The confirmatory analysis should estimate five binary main effects, four MMD contrasts against level zero, and prespecified interactions using paired records and seed blocks. It should not rank 160 cells and declare the maximum a discovery. The all-binary-on masks 1111110–1111114 form a kernel family; none is a generic “full loss” independent of kernel choice.

13.4 What remains before a defensible result

  1. Finish the five MSVAE and 37 ECG-AIM checkpoint cells or explicitly freeze a reduced estimand.
  2. Run identical, generation-bound missing-lead test inference.
  3. Preserve per-record pairing and patient clustering.
  4. Report optimization failures rather than silently dropping masks.
  5. Treat U-Net validation patterns as hypothesis generation until replicated.
