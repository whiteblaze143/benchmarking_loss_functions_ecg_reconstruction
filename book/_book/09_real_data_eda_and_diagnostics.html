4.2 PTB-XL: observed cohort and split contract

The local metadata contain 21,799 ECG records and 28 columns. The ten official stratification folds are nearly balanced (2,173–2,198 records each). The locked model registry maps folds 1–8 to training (17,418 records), fold 9 to validation (2,183), and fold 10 to test (2,198). The registry also reports 1,904 unique patients in the test set, so patient-clustered uncertainty is necessary: record-level resampling would treat repeated ECGs from the same person as independent.

The raw age field deserves an explicit validity audit. Its observed maximum is 300, which is not physiologically plausible as years and should not silently enter subgroup analysis. Age-based EDA must therefore report invalid-value counts and either use a documented correction supplied by the dataset or mark those values missing. It must not “fix” them by clipping without a sensitivity analysis.

4.2.1 Leakage checks that must precede modeling

  1. Patient separation: intersect patient IDs across train, validation, and test. Every intersection must be empty.
  2. File inventory: confirm every metadata row resolves to exactly one waveform tensor in its assigned split.
  3. Duplicate signals: hash waveform bytes after canonical dtype conversion. Metadata uniqueness alone cannot detect copied signals.
  4. Label derivation: parse scp_codes deterministically and version the superclass mapping.
  5. Preprocessing fit scope: any learned mean, variance, clipping threshold, or calibration parameter must be fit on training data only.

4.2.3 Executed PTB-XL waveform audit

The following block reads the actual paired WFDB records named by filename_hr and filename_lr in data/ptb_xl/ptbxl_database.csv. To keep HTML rendering reproducible and bounded, it uses a fixed, fold-stratified audit sample of 25 records from each official fold (250 records total); this is an EDA sample, not an inferential subsample. Primary signal summaries use the stored 500 Hz physical waveforms. The paired 100 Hz releases are upsampled to quantify what a 100→500 Hz adapter can and cannot recover.

Code 
import wfdb
from scipy.signal import resample_poly, welch

PTB_ROOT = (ROOT / "data/ptb_xl").resolve()
audit_rows = (
    ptb.groupby("strat_fold", group_keys=False)
       .sample(n=25, random_state=20260731)
       .sort_values(["strat_fold", "ecg_id"])
)
signals_hr = []
signals_lr_up = []
for row in audit_rows[["filename_hr", "filename_lr"]].itertuples(index=False):
    signal_hr, fields_hr = wfdb.rdsamp(str(PTB_ROOT / row.filename_hr))
    signal_lr, fields_lr = wfdb.rdsamp(str(PTB_ROOT / row.filename_lr))
    if fields_hr["fs"] != 500 or signal_hr.shape != (5000, 12):
        raise ValueError(f"Unexpected PTB-XL high-resolution contract: {row.filename_hr}")
    if fields_lr["fs"] != 100 or signal_lr.shape != (1000, 12):
        raise ValueError(f"Unexpected PTB-XL low-resolution contract: {row.filename_lr}")
    if fields_hr["sig_name"] != fields_lr["sig_name"]:
        raise ValueError(f"Lead-order mismatch: {row.filename_hr} vs {row.filename_lr}")
    signals_hr.append(signal_hr.astype(np.float32))
    signals_lr_up.append(
        resample_poly(signal_lr, up=5, down=1, axis=0).astype(np.float32)
    )
ptb_wave = np.stack(signals_hr)  # records × 5000 samples × leads
ptb_lr_up = np.stack(signals_lr_up)
fields = fields_hr
lead_names = fields["sig_name"]

4.2.4 The actual model-input tensor boundary

Raw WFDB EDA is necessary but not sufficient: the reconstruction code does not read WFDB files during training. scripts/train_mcma_3lead.py::PTBXLDataset loads .pt files, expects shape 12 × 5000, appends 120 zeros to reach a pooling-compatible length of 5,120, and selects lead indices [0, 1, 7]—I, II, and V2—as the model input. Targets contain all 12 padded leads. The training loader applies no per-record standardization, filtering, or amplitude clipping.

The following audit is computed over every tensor, not the 250-record raw-waveform sample. To keep routine book renders tractable, scripts/audit_ptbxl_tensors_for_book.py performs the 5 GB sequential scan with the project venv and writes a record-level Parquet plus a JSON summary. Each tensor is loaded through torch.load(..., weights_only=True) and checked for metadata/split alignment, shape, dtype, nonfinite values, flat leads, amplitude, RMS, and SHA-256 of canonical float32 signal bytes.

The gate distinguishes three failure classes. A perfectly matched inventory does not by itself prove the correct physical units, so the next two checks inspect the distribution and pair tensors back to the raw 500 Hz waveforms.

4.5 Signal-level EDA: what to measure

4.5.1 1. Units and inverse normalization

For each lead \(\ell\), recover clipped microvolts using

\[x_{\mu V,\ell}=z_\ell\sigma_\ell+\mu_\ell.\]

Then convert once to millivolts if the reconstruction model expects mV:

\[x_{mV,\ell}=10^{-3}x_{\mu V,\ell}.\]

A thousand-fold unit error can produce finite tensors and plausible-looking normalized plots while destroying inference. Unit tests should assert known percentile ranges before and after conversion.

4.5.2 2. Clipping occupancy

Compute the fraction of values equal, or numerically close, to each provenance bound by lead. High occupancy indicates censored amplitude tails. Report this because peak-amplitude and ST-deviation errors are then conditional on the released clipping policy.

In the released test tensor, approximately 0.120–0.144% of samples per lead lie at either documented clipping bound. The inverse-normalized microvolt percentiles show clinically meaningful lead heterogeneity: for example, the 0.1st/99.9th percentiles are −102/287 µV in lead I, −369/173 µV in V1, −527/299 µV in V3, and −246/426 µV in V5. 4.5.3 3. Lead-law residuals

The limb leads obey approximate linear relations:

\[III \approx II-I,\quad aVR \approx-\frac{I+II}{2},\quad aVL \approx I-\frac{II}{2},\quad aVF \approx II-\frac{I}{2}.\]

Residual distributions detect lead permutations, polarity errors, scaling inconsistencies, and corrupted records. These are pipeline diagnostics, not targets to “repair” after looking at test performance.

The actual EchoNext test tensor passes a strong version of this check after inverse normalization. Median record-level residual RMSE is 2.34 µV for \(III-(II-I)\), 0.86 µV for \(aVR+(I+II)/2\), 1.53 µV for \(aVL-(I-II/2)\), and 1.41 µV for \(aVF-(II-I/2)\). Corresponding 99th percentiles are 16.57, 7.44, 11.88, and 9.87 µV. These nonzero residuals reflect quantization/clipping and acquisition representation; they also provide empirical tolerances for future pipeline tests. A residual orders of magnitude larger than these references is a red flag for lead or unit corruption.

4.5.4 4. Spectral and morphology distributions

Report per-lead power in prespecified bands (baseline, P/T, QRS, high-frequency), R-peak count, RR variability, QRS width, QT/QTc, peak amplitude, and flatline fraction. Compare distributions before and after resampling. A global Pearson score can conceal loss of high-frequency QRS energy or systematic ST smoothing.

4.5.5 5. Cross-lead dependence

Plot the \(12\times12\) lead correlation matrix and the distribution of record-level condition numbers. Reconstruction difficulty depends on how much missing-lead information is identifiable from observed leads \(I\), \(II\), and \(V_2\) (indices 0, 1, 7 in the locked registry). Strong average correlation does not imply that diagnostically important residual variation is recoverable.

4.6 Deep reconstruction diagnostics

A useful diagnostic stack separates four questions.

Layer Question Minimum outputs
Sample fidelity Are point amplitudes close? MAE/MSE, bias, Bland–Altman, peak error
Shape fidelity Are morphology and timing preserved? Pearson, derivative error, DTW, delineation deltas
Physiologic consistency Do leads form a coherent ECG? Einthoven residuals, VCG trajectory error, interval consistency
Diagnostic utility Does a frozen model retain predictions? per-task AUROC/AP/F1, calibration, paired probability drift

Failure analysis should be record based, not figure based. Rank records separately by MSE, missing-lead Pearson, QRS error, ST error, classifier probability drift, and signal-quality score. The intersection and disagreement among those lists reveal different failure modes:

  • low MSE + poor classifier fidelity: small but task-aligned feature loss;
  • high MSE + stable classifier output: nuisance amplitude or baseline mismatch;
  • strong global Pearson + poor QRS correlation: localized depolarization failure;
  • good morphology + lead-law violation: cross-lead incoherence;
  • good mean performance + subgroup tail failure: deployment inequity.

4.7 Statistical design for the factorial benchmark

The locked experiment is a \(3\times2^4\) design: three architectures crossed with toggles for MSE (E), correlation (C), MMD (M), and derivative loss (D). The 48 cells permit main-effect and interaction estimates; comparing only “MSE” with “full” wastes most of the design.

Use paired patient-cluster BCa intervals because all cells predict the same test patients and some patients contribute multiple records. For each family and endpoint, estimate

\[\Delta_k=\mathbb{E}[Y\mid k=1]-\mathbb{E}[Y\mid k=0]\]

and prespecified two-way interactions. Family-wise morphology tests use the repository’s corrected threshold; exploratory downstream endpoints must be labeled exploratory. The existing results show significant QRS and ST improvements for full-versus-base in all three architecture families, while ECGFounder AUROC changes are not significant. That supports improved morphology without detected diagnostic-utility loss; it is not proof of clinical equivalence.

4.8 Reproducible audit checklist

  • Record exact file hashes and waveform shapes.
  • Assert patient-disjoint splits and stable record order.
  • Validate axis order, lead order, sampling rate, unit, and duration.
  • Quantify invalid demographics and structured missingness.
  • Report endpoint support before any classifier metric.
  • Preserve rare-task uncertainty; do not hide it in macro averages.
  • Compare pre/post-resampling spectra and intervals.
  • Inspect clipping occupancy and lead-law residuals.
  • Use patient-clustered paired inference.
  • Publish per-record outputs so tail failures remain inspectable.

### Executed PTB-XL waveform audit

The following block reads the actual paired WFDB records named by `filename_hr` and `filename_lr` in `data/ptb_xl/ptbxl_database.csv`. To keep HTML rendering reproducible and bounded, it uses a fixed, fold-stratified audit sample of 25 records from each official fold (250 records total); this is an EDA sample, not an inferential subsample. Primary signal summaries use the stored 500 Hz physical waveforms. The paired 100 Hz releases are upsampled to quantify what a 100→500 Hz adapter can and cannot recover.

```{python}
#| label: ptbxl-waveform-audit
#| tbl-cap: "Lead-wise audit of real PTB-XL WFDB waveforms (fixed 250-record stratified sample)."
import wfdb
from scipy.signal import resample_poly, welch

PTB_ROOT = (ROOT / "data/ptb_xl").resolve()
audit_rows = (
    ptb.groupby("strat_fold", group_keys=False)
       .sample(n=25, random_state=20260731)
       .sort_values(["strat_fold", "ecg_id"])
)
signals_hr = []
signals_lr_up = []
for row in audit_rows[["filename_hr", "filename_lr"]].itertuples(index=False):
    signal_hr, fields_hr = wfdb.rdsamp(str(PTB_ROOT / row.filename_hr))
    signal_lr, fields_lr = wfdb.rdsamp(str(PTB_ROOT / row.filename_lr))
    if fields_hr["fs"] != 500 or signal_hr.shape != (5000, 12):
        raise ValueError(f"Unexpected PTB-XL high-resolution contract: {row.filename_hr}")
    if fields_lr["fs"] != 100 or signal_lr.shape != (1000, 12):
        raise ValueError(f"Unexpected PTB-XL low-resolution contract: {row.filename_lr}")
    if fields_hr["sig_name"] != fields_lr["sig_name"]:
        raise ValueError(f"Lead-order mismatch: {row.filename_hr} vs {row.filename_lr}")
    signals_hr.append(signal_hr.astype(np.float32))
    signals_lr_up.append(
        resample_poly(signal_lr, up=5, down=1, axis=0).astype(np.float32)
    )
ptb_wave = np.stack(signals_hr)  # records × 5000 samples × leads
ptb_lr_up = np.stack(signals_lr_up)
fields = fields_hr
lead_names = fields["sig_name"]

finite = np.isfinite(ptb_wave)
lead_sd = ptb_wave.std(axis=1)
freq, psd = welch(ptb_wave, fs=500, axis=1, nperseg=1024)
band_power = {
    "baseline_<0.5Hz": np.trapz(psd[:, (freq < 0.5), :], freq[freq < 0.5], axis=1),
    "cardiac_0.5-40Hz": np.trapz(
        psd[:, (freq >= 0.5) & (freq <= 40), :],
        freq[(freq >= 0.5) & (freq <= 40)], axis=1
    ),
    "high_40-150Hz": np.trapz(
        psd[:, (freq > 40) & (freq <= 150), :],
        freq[(freq > 40) & (freq <= 150)], axis=1
    ),
}

ptb_signal_audit = pd.DataFrame({
    "lead": lead_names,
    "finite_percent": 100 * finite.mean(axis=(0, 1)),
    "p01_mV": np.quantile(ptb_wave, 0.01, axis=(0, 1)),
    "median_mV": np.median(ptb_wave, axis=(0, 1)),
    "p99_mV": np.quantile(ptb_wave, 0.99, axis=(0, 1)),
    "median_RMS_mV": np.median(np.sqrt(np.mean(ptb_wave ** 2, axis=1)), axis=0),
    "near_flat_records_percent": 100 * (lead_sd < 1e-4).mean(axis=0),
    "median_high_frequency_fraction": np.median(
        band_power["high_40-150Hz"] /
        np.maximum(
            band_power["cardiac_0.5-40Hz"] + band_power["high_40-150Hz"],
            1e-12
        ),
        axis=0
    ),
})
print(f"Loaded {len(ptb_wave)} paired 500 Hz/100 Hz real records from {PTB_ROOT}")
ptb_signal_audit
```

### The actual model-input tensor boundary

Raw WFDB EDA is necessary but not sufficient: the reconstruction code does not read WFDB files during training. `scripts/train_mcma_3lead.py::PTBXLDataset` loads `.pt` files, expects shape `12 × 5000`, appends 120 zeros to reach a pooling-compatible length of 5,120, and selects lead indices `[0, 1, 7]`—I, II, and V2—as the model input. Targets contain all 12 padded leads. The training loader applies no per-record standardization, filtering, or amplitude clipping.

The following audit is computed over **every tensor**, not the 250-record raw-waveform sample. To keep routine book renders tractable, `scripts/audit_ptbxl_tensors_for_book.py` performs the 5 GB sequential scan with the project venv and writes a record-level Parquet plus a JSON summary. Each tensor is loaded through `torch.load(..., weights_only=True)` and checked for metadata/split alignment, shape, dtype, nonfinite values, flat leads, amplitude, RMS, and SHA-256 of canonical float32 signal bytes.

## EchoNext: population, waveform, and endpoint audit

The local EchoNext metadata table contains **100,000 records and 39 fields**. The frozen external test array contains **5,442 × 1 × 2,500 × 12** values. At the declared 250 Hz, each trace spans 10 seconds. The singleton axis is a storage/channel wrapper, not an ECG lead. Lead order is explicitly:

$$[I,II,III,aVR,aVL,aVF,V_1,V_2,V_3,V_4,V_5,V_6].$$

The waveforms are stored as `float64` after official per-lead clipping and train-set z-scoring. Evaluation inverts that affine transform back to clipped microvolts before reconstruction inference. This is a critical domain-transfer detail because PTB-XL models expect 500 Hz, 5,000-sample, physical-mV inputs with no per-record normalization. Resampling, unit conversion, axis ordering, and inverse normalization must all be validated independently.

Only the EchoNext **test** waveform array is present under the local `data/echonext/` tree. Train, validation, and `no_split` waveform distributions therefore cannot be compared from this repository snapshot; their metadata are auditable, but claiming split-wise waveform parity would exceed the available artifact.

The 100,000-row metadata split is 72,475 train, 4,626 validation, 5,442 test, and 17,457 marked `no_split`. The unsplit records must not be silently added to training: their role is undefined by the local split field. The cohort is 53,581 male and 46,419 female records, with age 18–90 years (median 63; mean 61.18). Acquisition settings are heavily clinical—48,162 inpatient and 31,453 emergency records, compared with 17,194 outpatient and 3,191 procedural records—so this is not a consumer-wearable population sample.

Race/ethnicity counts are 31,013 Hispanic, 29,211 White, 16,461 Black, 3,428 Asian, 7,429 other, and 12,458 unknown. These are record counts rather than unique-patient counts and should not be presented as independent population denominators when patients have repeated ECGs.

## Signal-level EDA: what to measure

### 1. Units and inverse normalization

For each lead $\ell$, recover clipped microvolts using

$$x_{\mu V,\ell}=z_\ell\sigma_\ell+\mu_\ell.$$

Then convert once to millivolts if the reconstruction model expects mV:

$$x_{mV,\ell}=10^{-3}x_{\mu V,\ell}.$$

A thousand-fold unit error can produce finite tensors and plausible-looking normalized plots while destroying inference. Unit tests should assert known percentile ranges before and after conversion.

### 2. Clipping occupancy

Compute the fraction of values equal, or numerically close, to each provenance bound by lead. High occupancy indicates censored amplitude tails. Report this because peak-amplitude and ST-deviation errors are then conditional on the released clipping policy.

In the released test tensor, approximately 0.120–0.144% of samples per lead lie at either documented clipping bound. The inverse-normalized microvolt percentiles show clinically meaningful lead heterogeneity: for example, the 0.1st/99.9th percentiles are −102/287 µV in lead I, −369/173 µV in V1, −527/299 µV in V3, and −246/426 µV in V5. A single global clipping range or scale would therefore distort the precordial leads differently.

The rendered audit below independently reads a fixed 256-record sample from the 1.3 GB memory-mapped array, reverses the released affine normalization using `PROVENANCE.json`, and recomputes signal-validity and lead-law summaries. ### 3. Lead-law residuals

The limb leads obey approximate linear relations:

$$III \approx II-I,\quad aVR \approx-\frac{I+II}{2},\quad
aVL \approx I-\frac{II}{2},\quad aVF \approx II-\frac{I}{2}.$$

Residual distributions detect lead permutations, polarity errors, scaling inconsistencies, and corrupted records. These are pipeline diagnostics, not targets to “repair” after looking at test performance.

The actual EchoNext test tensor passes a strong version of this check after inverse normalization. Median record-level residual RMSE is 2.34 µV for $III-(II-I)$, 0.86 µV for $aVR+(I+II)/2$, 1.53 µV for $aVL-(I-II/2)$, and 1.41 µV for $aVF-(II-I/2)$. Corresponding 99th percentiles are 16.57, 7.44, 11.88, and 9.87 µV. These nonzero residuals reflect quantization/clipping and acquisition representation; they also provide empirical tolerances for future pipeline tests. A residual orders of magnitude larger than these references is a red flag for lead or unit corruption.

### 4. Spectral and morphology distributions

Report per-lead power in prespecified bands (baseline, P/T, QRS, high-frequency), R-peak count, RR variability, QRS width, QT/QTc, peak amplitude, and flatline fraction. Compare distributions before and after resampling. A global Pearson score can conceal loss of high-frequency QRS energy or systematic ST smoothing.

### 5. Cross-lead dependence

Plot the $12\times12$ lead correlation matrix and the distribution of record-level condition numbers. Reconstruction difficulty depends on how much missing-lead information is identifiable from observed leads $I$, $II$, and $V_2$ (indices 0, 1, 7 in the locked registry). Strong average correlation does not imply that diagnostically important residual variation is recoverable.

## Deep reconstruction diagnostics

A useful diagnostic stack separates four questions.

| Layer | Question | Minimum outputs |
|---|---|---|
| Sample fidelity | Are point amplitudes close? | MAE/MSE, bias, Bland–Altman, peak error |
| Shape fidelity | Are morphology and timing preserved? | Pearson, derivative error, DTW, delineation deltas |
| Physiologic consistency | Do leads form a coherent ECG? | Einthoven residuals, VCG trajectory error, interval consistency |
| Diagnostic utility | Does a frozen model retain predictions? | per-task AUROC/AP/F1, calibration, paired probability drift |

Failure analysis should be **record based**, not figure based. Rank records separately by MSE, missing-lead Pearson, QRS error, ST error, classifier probability drift, and signal-quality score. The intersection and disagreement among those lists reveal different failure modes:

- low MSE + poor classifier fidelity: small but task-aligned feature loss;
- high MSE + stable classifier output: nuisance amplitude or baseline mismatch;
- strong global Pearson + poor QRS correlation: localized depolarization failure;
- good morphology + lead-law violation: cross-lead incoherence;
- good mean performance + subgroup tail failure: deployment inequity.

## Statistical design for the factorial benchmark

The locked experiment is a $3\times2^4$ design: three architectures crossed with toggles for MSE (E), correlation (C), MMD (M), and derivative loss (D). The 48 cells permit main-effect and interaction estimates; comparing only “MSE” with “full” wastes most of the design.

Use paired patient-cluster BCa intervals because all cells predict the same test patients and some patients contribute multiple records. For each family and endpoint, estimate

$$\Delta_k=\mathbb{E}[Y\mid k=1]-\mathbb{E}[Y\mid k=0]$$

and prespecified two-way interactions. Family-wise morphology tests use the repository's corrected threshold; exploratory downstream endpoints must be labeled exploratory. The existing results show significant QRS and ST improvements for full-versus-base in all three architecture families, while ECGFounder AUROC changes are not significant. That supports improved morphology without detected diagnostic-utility loss; it is **not** proof of clinical equivalence.

## Reproducible audit checklist

- Record exact file hashes and waveform shapes.
- Assert patient-disjoint splits and stable record order.
- Validate axis order, lead order, sampling rate, unit, and duration.
- Quantify invalid demographics and structured missingness.
- Report endpoint support before any classifier metric.
- Preserve rare-task uncertainty; do not hide it in macro averages.
- Compare pre/post-resampling spectra and intervals.
- Inspect clipping occupancy and lead-law residuals.
- Use patient-clustered paired inference.
- Publish per-record outputs so tail failures remain inspectable.
