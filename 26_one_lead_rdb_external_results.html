7.1 Protocol boundary

This is the external RDB evaluation for one-lead ECG-AIM checkpoints. It is not the three-lead RDB oracle or blinded evaluator. RDB supplies six genuine boundaries—P/QRS/T onset and offset. It does not supply peak annotations, so no P-, QRS-, or T-peak timing result is invented. Screening thresholds and upper-confidence-bound decisions are reported separately from raw performance.

7.11 Remaining inferential limits

These are single-checkpoint, single-seed model comparisons. The database stores aggregate endpoint summaries rather than paired per-record bootstrap contrasts between every model, so small differences are descriptive. Screening and full evaluation share the RDB cohort family, and no second external dataset validates the same one-lead model ranking. Clinical selection requires repeated seeds, patient-level paired uncertainty, and a predeclared endpoint hierarchy.

## Protocol boundary

This is the external RDB evaluation for one-lead ECG-AIM checkpoints. It is not
the three-lead RDB oracle or blinded evaluator. RDB supplies six genuine
boundaries—P/QRS/T onset and offset. It does not supply peak annotations, so no
P-, QRS-, or T-peak timing result is invented. Screening thresholds and
upper-confidence-bound decisions are reported separately from raw performance.

## Did the pilot preserve the full-test ordering?

```{python}
#| label: onelead-rdb-pilot-full
primary_metrics = ["primary_mean_micro_f1_20ms", "primary_record_f1_u99",
                   "primary_signal_pearson_p05", "primary_signal_pearson_p05_u99"]
pilot_full = model_evaluations.pivot_table(
    index="model_id", columns="stage", values=primary_metrics)
pilot_full_correlations = []
for metric in primary_metrics:
    pair = pilot_full[metric].dropna()
    pilot_full_correlations.append({
        "metric": metric, "models": len(pair),
        "Pearson": pair.pilot.corr(pair.full),
        "Spearman": pair.pilot.corr(pair.full, method="spearman")})
display(pd.DataFrame(pilot_full_correlations))
```

The 48-record pilot preserves boundary ranking reasonably well: full-versus-
pilot Spearman correlation is 0.869 for mean micro-F1 and 0.822 for the
record-level lower-tail statistic. It is much less reliable for raw signal
Pearson p05 (Spearman 0.450). Thus the pilot is defensible as a boundary screen,
but weak as a fine-grained selector for difficult-record waveform fidelity.

All 60 models were promoted, so this run does not estimate how many genuinely
poor candidates the thresholds would have rejected. Promotion should not be
described as independent confirmation; it is a selection stage followed by a
larger evaluation on the same cohort family.

## Do the spatial controls transport?

```{python}
#| label: onelead-rdb-spatial-transport
external_matrix = full_evaluations.pivot_table(
    index=["factorial_mask", "input_lead"], columns="variant",
    values=["primary_mean_micro_f1_20ms", "primary_signal_pearson_p05"])
external_contrasts = []
for metric in ["primary_mean_micro_f1_20ms", "primary_signal_pearson_p05"]:
    for label, candidate, reference in [
        ("E1 − A0", "e1_panorama_film", "a0"),
        ("E1 − permuted", "e1_panorama_film", "pg1_permuted_geometry"),
        ("E1 − capacity", "e1_panorama_film", "cm1_capacity_matched"),
        ("B1 − A0", "b1_panorama", "a0")]:
        delta = external_matrix[(metric, candidate)] - external_matrix[(metric, reference)]
        for (mask, lead), value in delta.items():
            external_contrasts.append({"metric": metric, "contrast": label,
                                       "factorial_mask": mask, "input_lead": lead,
                                       "difference": value})
external_contrasts = pd.DataFrame(external_contrasts)
display(external_contrasts)
fig = px.bar(external_contrasts, x="contrast", y="difference", color="input_lead",
             facet_row="metric", facet_col="factorial_mask", barmode="group",
             title="External matched spatial-control differences")
fig.add_hline(y=0, line_dash="dash")
fig.show()
```

The internally consistent geometry effect does not transport uniformly. For
external boundary F1, E1 minus permuted geometry ranges from −0.015 to +0.031
and E1 minus capacity control ranges from −0.007 to +0.028. For signal Pearson
p05, E1 is usually favourable on lead I but loses by 0.015–0.040 on lead II in
the `1110000` setting. The sign reversals mean that the external data weaken a
general physiology-specific advantage claim.

Simple B1 panorama is the external boundary leader for mask `1010010` on both
observed leads (0.6585 lead I; 0.6742 lead II), but it is below A0 for several
other mask/lead cells. This is selection heterogeneity, not a universal ranking.

## External evidence ledger

| Claim | Verdict | Evidence |
|---|---|---|
| The 48-record pilot is adequate for boundary screening | Reasonable, not definitive | Boundary rank correlations exceed 0.82; no rejected-model operating characteristic was observed. |
| The pilot precisely selects waveform lower-tail performance | Not supported | Signal-p05 pilot/full Spearman is 0.45. |
| Internal reconstruction ranking transfers to RDB | Partially | Moderate correlations, with substantial residual rank changes. |
| E1 geometry has a robust external advantage | Not supported | Matched control effects reverse sign across masks, leads, and endpoints. |
| B1 is the universal best architecture | Not supported | It leads boundary F1 for `1010010` but loses in other cells and on other endpoints. |
| The best model depends on intended use | Supported | Boundary timing, region overlap, mean signal fidelity, and lower-tail fidelity select different checkpoints. |

## Remaining inferential limits

These are single-checkpoint, single-seed model comparisons. The database stores
aggregate endpoint summaries rather than paired per-record bootstrap contrasts
between every model, so small differences are descriptive. Screening and full
evaluation share the RDB cohort family, and no second external dataset validates
the same one-lead model ranking. Clinical selection requires repeated seeds,
patient-level paired uncertainty, and a predeclared endpoint hierarchy.
