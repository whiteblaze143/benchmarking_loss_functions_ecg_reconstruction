# LUDB Oracle-Label Fidelity Evaluation Plan

Latest version: `LUDB_ORACLE_EVALUATION_PLAN_20260822_001000.md`.

LUDB cardiologist timestamps are the fixed clock. The primary V1/V3–V6 evaluation measures exact-index landmark voltage error, baseline-corrected wave amplitude/area and fixed-window shape, ST/J fidelity, and ordinary signal/derivative error. It emits no automatic boundaries, no timing MAE, no artificial Dice, and no weighted winner score. NeuroKit is retained only as an already-stopped catastrophe detector.
