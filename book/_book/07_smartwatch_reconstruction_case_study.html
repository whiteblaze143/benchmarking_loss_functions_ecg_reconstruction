15 Smartwatch Simulator Transfer and Frozen-Classifier Fidelity

This chapter reads the current factorial_v4_clinical artifacts directly. It separates two estimands: device/protocol measurement error against programmed simulator values or paired Philips recordings, and frozen-classifier probability fidelity between reference and reconstructed waveforms. Neither supplies human diagnostic ground truth. The task table records ground_truth_status = unavailable; clinical accuracy and interchangeability are not estimable here.

WarningRelease status

Core and clinical computation are complete, but the repository-wide final checker is 9/10 because the fresh post-run audit returned REVIEW_UNAVAILABLE. These are empirical artifacts, but the package is not finally promoted or independently reviewed.

def sha256_file(path):
    digest = hashlib.sha256()
    with path.open("rb") as handle:
        for chunk in iter(lambda: handle.read(1024 * 1024), b""):
            digest.update(chunk)
    return digest.hexdigest()

protocol = pd.read_csv(PROTOCOL_CSV)
fidelity = pd.read_csv(FIDELITY_CSV)
completion = json.loads(COMPLETION_JSON.read_text())
expected_devices = {"applewatch_serie8", "fitbitsense2", "samsunggalaxy6", "withingsscanwatch"}

assert fidelity.task_name.nunique() == 150
assert fidelity[["model_id", "device", "task_name"]].duplicated().sum() == 0
assert len(fidelity) == 48 * 4 * 150
assert set(fidelity.ground_truth_status) == {"unavailable"}
assert set(fidelity.evaluation_type) == {"frozen_classifier_probability_fidelity_proxy"}

15.3 Frozen-classifier probability fidelity

For task (k), reference probability (p_{ik}), and reconstructed-waveform probability (p_{ik}), the table reports

\[\operatorname{MAE}_k=\frac{1}{n}\sum_i|\hat p_{ik}-p_{ik}|,\]

correlation, divergence, and fixed-threshold agreement. Threshold agreement is not accuracy: the reference classifier decision is the comparison target because patient labels are unavailable.

15.5 Interpretation boundary

The artifacts show that reconstruction changes a frozen classifier’s probabilities and that change varies across tasks, devices, architectures, and objectives. Before a clinical transfer claim, the study still requires record-level outputs joined to independently adjudicated labels, patient-level identity and clustered uncertainty, prespecified primary tasks and multiplicity control, simple baselines, per-lead waveform endpoints, alignment sensitivity, protocol-stratified failure cases, and a passed independent post-run audit.
