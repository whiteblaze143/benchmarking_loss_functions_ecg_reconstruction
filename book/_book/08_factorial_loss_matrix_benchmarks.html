This chapter reports the completed factorial_v4 generation: three architecture families crossed with sixteen four-bit objective masks at seed 42. It does not pool the separate 480-job mixed-level U-Net study, whose live protocol and completion gates appear in Chapter 12.

The identifier family__e?c?m?d?__s42 encodes pointwise MSE (E), correlation loss (C), repaired adaptive multiscale RBF MMD (M), and first-derivative loss (D). Primary confirmatory factorial inference is restricted to the MSE-on (2^3) design. The full MSE toggle is supplementary because a historical MultiScale-VAE decoder-loss defect made eight MSE-off/on checkpoint pairs identical; the quarantine is part of the artifact contract.

WarningClaim status

Core tables are complete and protocol-audited, but the repository-wide final checker remains 9/10 because the independent fresh post-run review was unavailable. Results below are generation-bound empirical estimates, not a claim of clinical equivalence or final external review.

def sha256_file(path):
    h = hashlib.sha256()
    with path.open("rb") as f:
        for chunk in iter(lambda: f.read(1024 * 1024), b""):
            h.update(chunk)
    return h.hexdigest()

13.3 Fidelity–morphology Pareto surface

Code 
import plotly.express as px

def nondominated(group, x, y):
    values = group[[x, y]].to_numpy()
    return np.array([not np.any((values[:,0] >= a) & (values[:,1] >= b) &
                                ((values[:,0] > a) | (values[:,1] > b))) for a,b in values])

valid_master = master.loc[master.inference_status == "valid"].copy()
valid_master["nondominated"] = valid_master.groupby("family", group_keys=False).apply(
    lambda g: pd.Series(nondominated(g, "pearson", "qrs_correlation"), index=g.index),
    include_groups=False,
).sort_index()
fig = px.scatter(valid_master, x="pearson", y="qrs_correlation", color="family", symbol="nondominated",
                 hover_data=["id", "mask4", "inference_status", "mse", "st_correlation", "ecgfounder_auroc"])
fig.update_layout(height=520)
fig.show()

QRS morphology versus global missing-lead Pearson for all registered cells. Outlined points are nondominated within family for these two higher-is-better endpoints.

This is a two-endpoint descriptive Pareto view, not a universal ranking. Changing either endpoint changes the frontier.

# Generation-Bound 48-Cell Factorial Benchmark {#sec-factorial-v4}

This chapter reports the completed `factorial_v4` generation: three architecture families crossed with sixteen four-bit objective masks at seed 42. It does not pool the separate 480-job mixed-level U-Net study, whose live protocol and completion gates appear in Chapter 12.

The identifier `family__e?c?m?d?__s42` encodes pointwise MSE (E), correlation loss (C), repaired adaptive multiscale RBF MMD (M), and first-derivative loss (D). Primary confirmatory factorial inference is restricted to the MSE-on (2^3) design. The full MSE toggle is supplementary because a historical MultiScale-VAE decoder-loss defect made eight MSE-off/on checkpoint pairs identical; the quarantine is part of the artifact contract.

    h = hashlib.sha256()

import plotly.express as px

def nondominated(group, x, y):
    values = group[[x, y]].to_numpy()
    return np.array([not np.any((values[:,0] >= a) & (values[:,1] >= b) &
                                ((values[:,0] > a) | (values[:,1] > b))) for a,b in values])

valid_master = master.loc[master.inference_status == "valid"].copy()
