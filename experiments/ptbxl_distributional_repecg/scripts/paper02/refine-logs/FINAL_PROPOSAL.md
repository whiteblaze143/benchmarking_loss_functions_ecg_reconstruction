# Final Proposal: Paper 02

## Problem Anchor
Kernel mean embedding for ECG distributions

## Core Thesis
Distributional metrics in RKHS capture functional abnormalities better than point estimates.

## Inductive Biases and Assumptions Embedded
The model architecture assumes that `Distributional metrics in RKHS capture functional abnormalities better than point estimates.`. By explicitly structuring the network to reflect this bias, we restrict the hypothesis space to physiologically plausible functions.

## Rejected Complexity
We reject over-parameterized black-box approaches in favor of a targeted inductive bias that can be validated via specific ablation variants.
